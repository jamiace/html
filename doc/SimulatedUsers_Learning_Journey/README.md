## 用法
- 多頁版：解壓縮 ZIP，開啟 `index.html`。
- 單檔版：直接開啟 `SimulatedUsers_Learning_Journey_v4.html`，所有章節與互動均內嵌。
- 若要取用JSON／MD參考資料，多頁ZIP內`reference/`資料夾有來源檔。

## 重要限制
Purr Cozy人物設計是測試假設，並非真人。單頁互動模式採示範模型，並非原本的正式測試數據；覆蓋測試不能推論自然留存。
