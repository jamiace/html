這個案例有三個不同時間點，不能混在一起

1

早期的角色設計

包含 30 位具備不同年齡、英文程度、作息和偏好的模擬人物，以及多種使用頻率與休眠型態。

2

後期的功能覆蓋

為了確保每日有足夠功能與題型資料，加入每人每天固定場次，造成原本會低頻使用的人也被強制出現。

3

規劃中的真人驗證

後續需要真實受試者，才有機會回答實際留存、自然動機、介面理解及市場受眾等問題。

哪裡可以找到完整方法？

整理後的方法與原始設定，一併收錄在 ZIP 的 reference/ 資料夾。

  • 原始 30 人試玩計畫
  • 30 位人物 JSON
  • 給 AI 的完整方法說明
  • 任務輸入 JSON
  • A2A Agent Card JSON

若要分享給其他部門，請先從首頁與「把方法帶到別處」開始。完整數值設定留給需要深入實作的人。

最後想留下的一句話

學會怎麼模擬一個使用者，只是第一步。
真正有意思的是，開始發現自己的知識還能做些什麼。

對不同的人而言，這個「還能做些什麼」可能指向教材、產品、服務、流程、AI 助教或其他完全沒想過的方向。先從一個小實驗開始即可。
