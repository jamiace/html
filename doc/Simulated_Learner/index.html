模擬學習者／使用者方法指南

這份指南在教什麼？

它不是教你「亂造幾個假帳號」；它教的是：如何建立一群有能力差異、時間限制、動機起伏、記憶與挫折變化，而且會在多天內持續互動的模擬使用者。

你可以把它用在學習遊戲、線上課程、企業系統、電商、AI 教學助理，或任何需要先低成本驗證流程與行為假設的產品。

最重要原則：不要把模擬數據偽裝成真人證據

先看哪一頁？

  • 完全新手：從「初學者」頁開始，先學會 3 個人物、7 個欄位。
  • 已經懂測試：直接看「進階者」頁，學狀態機、事件紀錄、驗證切分。
  • 要交給 AI：看「給 AI 的規格」，可直接複製到 LLM / Agent 任務。
  • 要做多 Agent：看「A2A」頁。
這份方法最適合拿來做：流程驗證、錯誤重現、情境覆蓋、假設比較。不適合直接宣稱市場留存率或學習成效。

你會學到的核心觀念

  1. 每個模擬人物都要有「身分、能力、目標、喜好、時間條件、挫折反應、可變狀態」。
  2. 一天內做什麼，不應該只靠亂數，而是由狀態 → 觸發 → 決策 → 回饋 → 更新狀態驅動。
  3. 為了覆蓋所有功能而強制安排任務，與觀察自然行為，是兩件不同的事。
  4. 所有事件都要能追溯：人物 ID、時間、模式、種子、結果、狀態變化。

常見誤解

誤解 1：我有 30 個模擬人，就等於有 30 個真人。
更正：不是。你有的是 30 組行為假設。
誤解 2：只要後台圖表很漂亮，就代表人物設計成功。
更正：如果你為了補資料而強制人物每天上線，圖表再漂亮也不能代表自然行為。
誤解 3：讓 LLM 每一步即興編故事就好。
更正：真正可用的測試需要規則、狀態與可重現證據。
