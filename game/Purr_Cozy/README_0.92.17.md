# Purr Cozy 0.92.17
覆蓋原 0.92.16 資料夾，不要刪除其他檔案。部署時最後上傳 version.json。

取消 SHA-256 驗證與以雜湊命名的素材快取。每次開啟遊戲直接抓取伺服器素材，下載失敗時使用同版本已存的本機檔案；全部素材準備好才進房間。舊 resources.bin 不再讀取，可刪除。原有存檔不清除。

修改現有 PNG 並保留路徑、尺寸：只上傳該 PNG，重新開啟遊戲即可，不必重建清單。若改檔名、尺寸、圖集或新增素材，仍要更新對應 catalog／圖集資料，並執行 Rebuild-Resources.cmd。程式功能發布仍需增加 version.json 版本。這不是離線時也能取得新圖片；離線僅有最後下載內容。

全面檢查 1080 款家具：移除坐墊、地毯、杯子、茶點、桌子、裝飾、植物等強制新視窗；恢復筆電與螢幕原本行為，以及原有功能入口。保留適合的樂器、掌機、拼圖、積木、織具、打字機玩法。原生開關優先，包括街機。

完整清單見 docs/furniture-interactions.html。舊 0.92.16 介紹與說明已不適用。
