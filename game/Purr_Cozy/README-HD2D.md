# 小窩時光 v0.92：HD-2D 首階段可操作體驗

先讀 README-ui-retry.md，本包已包含明暗介面與重試流程修正。遊戲版本仍為 0.92。

## 開啟方式
這是完整網頁專案，解壓到同一個目錄，不要用 file:// 直接開啟 HTML。可在該目錄執行 `python3 -m http.server 8000`，再開啟 http://localhost:8000/hd2d.html。

- hd2d.html：團圓夜 HD-2D 體驗入口；進度獨立保存在本機，正式存檔不會被覆寫；此入口不連接正式雲端帳號。
- index.html：一般遊戲入口，預設沿用原本畫面，可在設定啟用 HD-2D。正式上站前請保留自己的圖示、字型、音樂與站台 Firebase 設定；本機體驗不需要登入。
