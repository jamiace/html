# Pocket Nook 0.92 — 第二批 HD-2D

請先安裝第一批更新，再將本包的 `js` 與 `assets` 資料夾合併覆蓋到遊戲根目錄，重新整理網頁即可。版本維持 0.92，不需修改 index.html。

完成 122 個基礎造型，涵蓋 222 款商品與配色：床與六款主題床、各式桌子、盆栽花卉，以及杯壺、唱片機、魚缸等桌面小物。使用內建繪圖工具逐款重繪，原像素素材保留。

本包只新增第二批圖片；圖包清單保留第一批的 60 張 HD 圖與椅背，再加入第二批 122 張，合計 182 張。第一批椅背方向與配色邏輯維持。

另外修正天蓬床與雙層床的睡姿遮擋：原本固定從第 18 像素重畫棉被，會蓋住高枕位的頭部；現在依各床睡姿座標決定遮擋高度。一般床與日式床墊的原本遮擋位置維持，此修正同時適用像素版與 HD-2D。

開啟 `preview.html` 查看全批素材；`HD2D-BATCHES.json` 記錄五批品項，前兩批已完成，後續從第三批接續。繪圖提示詞見 `ART-PROMPTS.json`，驗證內容見 `TEST-REPORT.md`。

安裝檔案：`js/actors.js`、`assets/hd2d/objects.json`、`assets/hd2d/objects/` 中本批 122 張 PNG。場景仍採 2 倍畫布，沿用既有光照、影子與天氣程式。
