# Purr Cozy 0.92.26：收納、指定貓咪動作、家具互動圖層與尿漬

適用目前 0.92.25。此包保留現有家具主圖，採用指定 ZIP 的貓咪動作與非家具效果圖，補齊必要互動圖層及程式／資料。沒有重新包入家具主圖，也沒有覆蓋音樂或存檔。

## 收納修正

js/ui.js 的 w_storage() 用 id 逐件列出庫存，預覽卻讀取不存在的 e.id，導致有家具庫存時拋出 ReferenceError，中斷開啟視窗。已改成正確的 id。桌機、手機與佈置模式的收納入口共用此方法。

## 素材來源

- 指定來源為 Purr_Cozy_0.92.24_SNES_Pixel.zip。五種毛色、八種動作共 400 張 PNG，以及尿漬、打翻、雪花、火花、食物五張效果圖，均逐檔原樣採用，沒有重畫或縮放。
- 打架的原始姿勢圖也取自 ZIP；依先前要求，實際畫面仍以中央共用的一團卡通煙霧遮住貓咪本體，不表現撕咬抓傷。煙團沿用目前版本，獨立存為效果圖。
- 目前家具主圖逐檔保持不變，只新增所需遮擋 PNG 與五張新椅子的背面圖。原有貓咪日常圖集及配件圖集沿用目前版本，來源 ZIP 並未提供這些完整圖集。

## 家具互動清查與補完

清查 catalog.json 內 1,380 件家具，為 498 件具有角色／寵物互動資料的物件補齊或整理設定。共輸出 641 張必要輔助圖層，涵蓋 44 張床、140 個座位／工作椅、桌面、貓跳台、貓窩及貓砂盆。

- 新增五張床先前只有 bed:true，缺少角色定位。已補上床上定位、枕頭位置與被褥起點，避免睡眠座標變成 NaN。
- 睡覺使用家具底圖→角色閉眼頭部→被褥／床沿前景；上下舖、四柱床另外保留前方結構遮擋。原有有效的睡眠定位與被褥起點保留。
- 坐下使用座位定位及扶手／座緣前景。靠桌或用功的椅子使用背面；獨立擺放保留正面。原本工作椅的點擊行為保留。
- 沙發閱讀仍保留 sitread 與手上書本，工作仍保留打字與伸展，不因新圖層失去原有動作。
- 貓咪停留於桌面、坐墊、床、貓窩與平台時，使用對應前緣。跳躍中不套用靜止遮擋層；新增貓跳台補上三段上下跳路徑。新床的貓咪停留點移至被褥區，避開主人頭部。
- 貓砂盆以實際寬高定義進入開口與前緣，修正窄款套用固定 8 像素邊距造成的過度裁切。
- 新增高櫃接回造型入口，格子收納櫃接回收納入口。

資料實際登錄於 assets/png/catalog.json；data/furniture-interactions.json 是供檢視與後續引擎串接的匯出資料。js/furniture-layers.js 負責佔用圖層、角色定位及地板尿漬行為；bootstrap.js 已接入載入順序。

## 尿漬修正

圖片本來存在，已重新引用指定 ZIP 的 effect_urine.png。另修正下列流程：

- 搗蛋／高壓亂尿事件即使找到床或坐墊，仍有機會選擇地板，而非永遠優先家具。原本事件頻率與冷卻保留，並限制同時髒亂數量。
- 地板亂尿先走到可見的空位，播放蹲姿，動作完成才留下尿漬；切換房間、存檔或進入佈置時取消尚未完成的事件。空房間也支援。
- 家具尿漬依床、座位與表面定位顯示，不一律畫在家具腳下；點擊可由主人手動清理。
- 地板尿漬可以點擊清理；新增與清除均納入雲端的進度變更判定。合併保留未清理紀錄與清理標記，避免舊存檔使尿漬消失，或把清理過的尿漬復活。
- 不憑空新增舊尿漬；顯示既有存檔紀錄與遊戲新產生的事件。

## 安裝

先備份，再將本包內容全部覆蓋到 Purr_Cozy 根目錄（index.html 所在層），不要刪除原資料夾。保留家具主圖、音樂、單字與存檔。執行一次 Update-Game.cmd，以本機完整檔案重建資源清單，將所有變更一同 commit／push 一次即可，不需部署後補傳版本檔。

版本改為 0.92.26，仍由 version.json 統一判定。沒有直接修改你的 D 槽專案，也沒有部署。
