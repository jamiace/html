# Purr Cozy 0.92.13 — 自適應英文測驗

將本包檔案依原路徑合併覆蓋在 **0.92.12** 遊戲資料夾，包含新增的 `js/adaptive.js`。不要刪除原資料夾。發佈網站時要一併上傳全部更新檔，完成後重新整理；版號只讀取 `version.json`。

## 遊玩行為

- 全部英文測驗共用自適應出題：日常單字、一般練習、換物資、寵物訓練、好友幫忙、每日英文挑戰、團隊英文任務、玩家／寵物升級、旅行商人劇情、Meow Typo。
- 以約 85% 答對率為出題目標，自動依答對／答錯微幅調整，不需要玩家設定程度。這是估計目標，不保證每一場、每位玩家恰好達成 85%。題庫、玩家選定等級與劇情內容會限制可選題目。
- 字義、聽力、拼字、聽音拼字分別記錄能力與近期 20 次首次作答，越新的作答權重越高。Meow Typo 與一般拼字共用拼字能力；提示／無提示會影響難度估計。
- 舊玩家利用既有單字學習紀錄提供初始程度；新玩家從所選等級的低端開始。這不是正式能力分級，也不宣稱是 CEFR 等級。
- 每次作答都更新能力。一般測驗在未出示題目中重新挑選下一題；新一場會依最新能力選字。Meow Typo 自由練習每題從符合規則的題庫重新挑選，避免同場重複。
- 保留適合程度的到期複習、錯字與新字。預習翻卡不算答對；同場同字同能力只計首次結果，重試不會把程度洗高。

## Meow Typo

- 自由練習及每日拼字任務都納入自適應。
- 玩家打字過程不扣程度，送出才評估；錯誤後改對仍可完成題目，但不改寫首次作答結果。
- 輸入中仍有可追蹤的貓咪亂按字元時，錯誤送出不計入能力估計；刪除干擾字後恢復正常評估。手動輸入與刪除會維護這些字元標記。
- 顯示答案記為未獨立答出；同字重排與每日任務重新進入不會重複計算該能力結果。
- 保留每字母底線、超出長度的輸入、打字機與 Enter 音效、單字語音合成、貓叫、答對自動下一題和測驗音樂降音量。

## 任務、劇情與存檔

- 已固定的每日任務單字保持不變，調整未出題單字的順序；已預習的測驗不會突然塞入未預習單字。
- 新字挑戰從玩家勾選等級中挑選適合程度、尚未學過的字，不再固定跳到上一級。
- 普通／困難的題數、無提示規則、獎勵與通關門檻保留。困難題仍納入能力紀錄。
- 旅行商人新生成的每週故事從該商人的主題字庫配對程度；已儲存劇情與上下文答案保持一致，不會為了配對程度改掉情節或命名答案。
- 能力放在 `learn.adaptive`，隨原本本機與雲端存檔保存；每日任務首次評估記號放在該任務的 `adaptiveAttempts`。雲端衝突時保留更新時間較新的完整能力模型，不加總共同來源的紀錄，避免重複計算。離線裝置分支同時作答時不合併兩份模型的所有答案。
- 近期能力字詞明細最多 1,000 筆、近期出題 40 筆；原有單字 SRS 紀錄不刪除。

## 維護與驗證

- 共用邏輯：`js/adaptive.js`；版本來源：`version.json`。
- 單字難度以題庫等級、拼字長度、題型、提示與個人熟悉度估計，尚未經真實學生作答資料校準。
- 自動測試包含能力分離、近期加權、難度方向、等級限制、複習混合、重試去重、所有測驗入口、Meow Typo 貓咪字元排除、每日任務進度、本機保存／重新載入、雲端合併與手機螢幕鍵盤。
- 另以假設難度模型的模擬玩家檢查調整是否收斂；這只能驗證程式方向，不能當成真實玩家達到 85% 的證據。
- 英文發音仍使用瀏覽器 SpeechSynthesis，沒有新增不存在的單字 MP3。
