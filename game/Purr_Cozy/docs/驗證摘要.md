# 0.92.14 驗證摘要

基準為已交付的 Web 0.92.13；測試日期 2026/10/30。

## 已完成的檢查

- 在 Chromium 實際啟動遊戲，完整取得並驗證 3638 個本地資源，約 47.2 MB。
- 1,408 組人物 PNG 合成結果與改造前逐張比較：髮型、五官、衣服、配件、動作、眨眼、上下浮動與鏡像結果一致。
- 全部 1080 個家具品項可取得圖片並繪製。
- 貓咪的所有動作、配件與五種毛色組合可取得 PNG 並顯示。
- 十一套可購買主題：單次正確扣款、重複套用不重複給物、不改動其他已放置家具的位置。
- 兩扇窗戶只替換一扇；沒有窗戶或書桌時不強制新增。
- 刻意填滿房間後套用主題：將三件必要物品移回收納，物品總數不減少。
- 椅子靠桌、獨立與坐人三種狀態；靠桌與坐人採用同一張背面，獨立使用正面。
- 貓砂盆乾淨與滿盆的 PNG 不同。
- 桌機商店、商人、換裝、寵物、學習、番茄鐘、Meow Typo 視窗，以及 320 像素手機視窗可開啟。
- Meow Typo 可輸入、送出、判答，打字機與 Enter 音效仍走原有 AudioBuffer。英文單字仍使用 SpeechSynthesis；沒有新增或依賴不存在的單字 MP3。
- 第二次啟動：素材下載數為零。
- 模擬升版僅修改一張 PNG：下載數為一，未重新下載整個素材包。測試用版號未寫入交付檔。
- 損壞更新：停止在開場並顯示重試，上一份完整快取仍能使用。
- 在巢狀網站路徑註冊實際 service worker 後，斷網重新整理成功，程式、字型與圖片均來自本機。
- 5156 個圖集圖框皆在圖片範圍內；1,242 份 Godot .tres 引用路徑存在。

## 測試界線

本次未登入玩家 Google 帳號、未更動雲端存檔，也沒有改變 Firestore 規則。雲端與 YouTube／天氣的線上服務功能保留原流程。測試環境沒有 Godot 編輯器，因此 Godot 部分完成素材與資源靜態檢查，未宣稱已在編輯器 F5 執行。

來源專案省略的 music 資料夾不在本包內，部署時請沿用原檔；放回後執行 Rebuild-Resources.cmd 可一起納入預載。
