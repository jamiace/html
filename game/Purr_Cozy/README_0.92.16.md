## 如何遊玩

直接點房間裡的家具。具有既有主要操作的家具保留原操作；可玩物件會開啟「家具小時光」。

- 鋼琴、吉他、風鈴、音樂盒：點琴鍵，或用 A S D F G H J K 彈奏；也能聽完旋律再彈回來。
- 街機、掌機、火箭模型：等待訊號，按下測反應；提早按不計成績。
- 魔術方塊：可解的1–8滑塊排序。不是三維魔術方塊模擬。
- 積木、衝浪板：對準移動中的積木，連續疊五層。
- 玩偶、擺飾：使用現有家具PNG玩四組翻牌配對。
- 織布機、縫紉機、刺繡等：選色填格，織出完整圖樣。
- 植物與花器：每日照料記錄、累計照料天數；缺水、清潔等原有任務仍優先處理。
- 茶具、咖啡機與點心：準備8秒後享用；原有咖啡機的每日供給規則沿用。
- 地毯、抱枕、流水與沙漏：30秒呼吸休息，不變更番茄鐘。
- 貓咪家具：招呼最近且有空的貓咪，或開啟照護、訓練；睡覺中的貓咪不強制叫醒。
- 書籍與電腦：學習、Meow Typo、專注與待辦入口。英文測驗仍使用既有自適應與語音合成。
- 櫃子、衣帽架、鏡子：收納或造型入口；唱片、耳機與喇叭：音樂入口。
- 相機：下載目前房間的照片；雨傘桶：查看已取得天氣及天氣設定，不會自動要求定位。
- 畫作、紀念品等：鑑賞、圖案配對、家具故事；水晶球等可看每日靈感問題。

展開「為這件家具留一段故事」可保存筆記。每款家具共享該款的紀錄與最佳成績；不同配色款式分別記錄。筆記每則240字，最多80則，不會自動刪除舊筆記。

小遊戲不新增金幣或經驗獎勵，避免破壞原有任務經濟。原本餵魚、澆水、咖啡機等獎勵沿用既有每日限制。

關閉活動、進入其他介面、切換存檔或隱藏分頁時，未完成的活動會停止；不會在背景自行判勝或發獎。

完整清單：docs/furniture-interactions.html，可離線開啟、搜尋全部家具；另有UTF-8 CSV清單。

新增文字已收錄 i18n/ui.json 的繁中／簡中／日文；預設繁中，沿用遊戲的語言設定。

## 驗證與界線

程式測試包含全部1080家具×三語介面（3240次）、六種遊戲、100組拼圖可解性、重複操作、每日照料、筆記序列化、換存檔、活動取消、最近貓咪及原有任務優先處理。音效已驗證WebAudio呼叫與開關，不冒稱已聽測所有實機。

本次啟動本機瀏覽器的動作遭自動核准審查拒絕，原因是環境不開放所需沙箱核准。因此未完成本次桌機／手機瀏覽器實測；附帶的手機版排版與觸控支援仍需實機驗收。

沒有直接改動原遊戲資料夾、雲端存檔或 Firebase 規則。

## 啟動驗證失敗修正

修正舊 service worker 忽略下載要求中 sha 雜湊、錯將舊PNG回傳給新版載入器的問題。新攔截器以要求的雜湊找檔；既有舊攔截器尚未更新時，載入器會從通過SHA-256驗證的素材包取回正確檔案。多個錯誤資源共用一次素材包下載。驗證仍然保留，不會放行損壞或不一致的檔案。

快取回歸測試通過：重現舊拉截器錯誤、新拉截器依雜湊取檔、兩張過期圖片共用一次素材包修復、損壞素材包拒絕安裝、準備期間保留舊版啟用標記。
