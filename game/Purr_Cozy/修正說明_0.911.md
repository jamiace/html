# Pocket Nook 0.911 修正說明

本次依指定使用 0.911，未另外遞增版號。原有存檔鍵值、資料結構版本與雲端設定維持相容。

## 音樂

- 專輯區不再被視窗的彈性排版壓到只剩部分封面。預設按專輯卡片實際高度呈現，最高 486px；超過範圍可捲動。
- 專輯區、歌曲清單下方各新增高度把手，可上下拖曳，兩者獨立調整。高度會記住，介面更新、關閉視窗或重開遊戲都會保留。
- 雙擊把手恢復該區預設高度；鍵盤聚焦後可用上下方向鍵調整，Home 恢復預設。手機也保留把手。
- 整個音樂視窗仍可從右下角調整大小；內部區域總高度超過視窗時，視窗內容可以捲動。
- 取消舊程式更新時強制改播 YouTube 的行為，記住上次選擇的內建、本機或 YouTube 曲目與播放位置。音樂庫排序改變時優先依曲目識別資料恢復。
- 上次的音樂庫暫時讀取不到時，保留原來源並顯示提示，不自動改播 YouTube。
- 沒有封面的音樂檔會正常完成讀取；網路失敗有 60 秒重試間隔，避免反覆下載封面、持續重建音樂介面。
- 房間更新迴圈已隔離介面、人物、生活系統及繪圖錯誤，單一錯誤不會中斷後續動畫更新。

## 禮物與互動訊息

- 禮物盒、折價券、保底資訊與重複物品說明改為靠左、完整換行。物品預覽仍置於中央。
- 連續操作家具時立即移除上一則家具訊息；不同人物、寵物仍各自保留其訊息。
- 電腦等長訊息會自動換行，不再以省略號截斷，靠近房間邊緣時也會調整位置。
- 對話泡泡改為鵝黃色邊框，邊框深於泡泡底色；泡泡與尾巴有圓角，不再使用黑色像素外框。

## 貓跳台

- 點擊貓跳台會呼喚有空的貓咪，走到下方後依序跳到中層、頂層，最後睡覺或坐著休息。
- 自主選擇貓跳台休息時使用相同分段路線；離開時也逐層跳回地面。
- 路線會隨家具翻轉，並保留其他貓咪占用位置的檢查。

## 旅行商人故事

- 點選已完成的章節數字即可回顧，支援上一章、下一章與返回本週故事。
- 回顧直接顯示故事，不進入測驗，也不改變獎勵、進度、命名、學習紀錄或收藏。
- 重複完成同章的呼叫不會再次發放金幣、經驗或紀念品。

## 驗證

使用 Chromium 實際執行專輯與清單高度調整、重新整理後的高度保留、長訊息、禮物盒排版、內建及本機音樂接續播放、舊存檔來源保留、故事回顧、貓咪分段上下跳台與手機版介面檢查。另注入音樂介面錯誤，確認房間與人物仍持續更新，並驗證封面失敗不會形成無限重試。

YouTube 以模擬播放器驗證原影片與播放位置的恢復流程；外部 YouTube、Google Drive 與 Firebase 正式服務未在此環境進行實際連線驗收。

## 替換

解壓縮後，以 pocket-nook 資料夾中的檔案覆蓋原專案，再依原本方式啟動或部署。遊戲不需要安裝 npm 套件。已開啟的遊戲頁面請重新整理，讓瀏覽器載入本次修正的程式與樣式。


## 同版追加：Android Firefox 登入、主畫面圖示與音樂白化

1. 手機與桌面都優先由登入按鈕直接啟動 Google 彈出視窗，不再因為直式畫面或主畫面 App 模式強制改用跨站跳轉登入。彈出視窗被封鎖時會提示允許後重試，不自動退回相同的失敗流程。
2. 帳號初始化時先設定登入持久化，依序使用 IndexedDB、本機儲存、分頁儲存；若只能保留於目前分頁，帳號頁會明確說明。所有儲存方式都不可用時顯示原因，不偽裝成可保持登入。
3. 登入回傳的使用者結果也會交給雲端進度載入流程，並避免與帳號狀態通知重複處理。讀取失敗時保留錯誤訊息。
4. 合併本次提供的 index.html，移除後方競爭的舊 favicon 與 Apple icon 宣告。分頁圖示、Apple 圖示、Android manifest 與通知圖示改用專案根目錄中的既有圖檔。
5. manifest 的主圖示使用 apple-touch-icon.png。因本次附件未包含實際圖檔，不虛填該 PNG 的尺寸；瀏覽器會讀取圖檔本身。若未來提供專用 Android 高解析圖示，可再按實際尺寸補入 manifest。
6. 修正音樂家具燈光使用十六進位顏色、引擎卻期待 warm/cool/pink 名稱的錯誤。加亮繪圖區段使用 try/finally 恢復狀態，並於每幀重設正常混色及透明度，避免音樂播放後物件白化。

### 覆蓋與手機驗收

- 將壓縮檔中的 pocket-nook 內容覆蓋原專案；以下三個自備圖檔須繼續放在 index.html 同一層：favicon.ico、icon-32x32.png、apple-touch-icon.png。本次只提供 HTML，未提供這三個圖檔，因此壓縮檔不會代換它們。
- 部署後，在 Android Firefox 的一般分頁重新整理遊戲，點「使用 Google 帳號登入」。若提示封鎖登入視窗，允許該網站的彈出視窗再試一次。
- 使用原本存有進度的同一個 Google 帳號，確認載入原有等級；若手機也已遊玩到有進度，會保留原有存檔選擇流程。
- 移除原本的主畫面捷徑，再從更新後的遊戲頁面新增。檢查新增時顯示的圖示及建立後的圖示。

### 驗證範圍

已透過模擬 Firebase 回應及瀏覽器手機版介面測試：Lv.1 裝置登入後讀回 Lv.18 雲端範例存檔、重開恢復帳號、不以空白進度覆蓋雲端、封鎖視窗錯誤、缺少使用者結果、登入儲存的各層退路、圖示宣告與相對路徑，以及音樂燈光例外恢復。

測試環境使用 Chromium 的手機尺寸及 Firefox 使用者代理，並非實體 Android Firefox。未使用真實 Google 帳號或正式 Firestore 資料，也無法在此環境驗收 Android Launcher 產生的主畫面捷徑；更新後需按上述步驟實機確認。

參考：Firebase 官方登入跳轉相容性說明 https://firebase.google.com/docs/auth/web/redirect-best-practices 、登入持久化 https://firebase.google.com/docs/auth/web/auth-state-persistence 、MDN manifest 圖示 https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Manifest/Reference/icons 。


## 同版追加：手機音樂控制列

手機音樂控制列改為五顆固定尺寸的按鈕，避免音量滑桿擠壓播放控制。一般按鈕為 44 × 44，中央播放／暫停按鈕為 52 × 52；圖示固定等寬等高，不受可用空間壓縮。手機版隱藏音量控制，改由裝置本身調整音量；桌面版保留原有音量控制。版號仍為 0.911。


## 同版追加：手機底部功能列

底列改為「學習／任務／寵物／音樂／更多」，移除用途重複的「房間」入口。一般功能視窗會保留底列空間，底列可直接切換功能；再點已開啟的同一項即可收合回房間。音樂已獨立放進底列，「更多」不再重複放音樂。需要完成的存檔移轉選擇仍會暫停功能切換，避免略過必要的存檔處理。


### YT 縮小播放器與關燈喚醒
- 縮小播放器可用標題列拖曳，位置會記在這台裝置；「置底」可隨時收回底部。手機置底時，房間與視窗會讓出空間，底部五個分頁仍可操作。
- 拖曳、縮小與置底只調整 CSS，不搬移或重建正在播放的 iframe。
- 關燈後貓咪不會因午睡計時結束而自行走動；叫醒時不再套用離線隨機換位，會從目前位置打呵欠、伸展，再以原本的走路／分段跳躍流程移動。
- F12 的 googleads.g.doubleclick.net/pagead/viewthroughconversion 缺少 CORS 標頭、HTTP 302 訊息，來自第三方追蹤請求。它本身不是房間白屏或 Canvas 例外；無法由本遊戲補上對方伺服器的回應標頭，也不應關閉瀏覽器安全限制或隱藏所有錯誤。真正的 YouTube 播放錯誤仍由播放器事件處理。
- 顯示版號仍為 0.911；快取識別更新只為取得本次修正檔。


### 本次追加驗證
使用 Chromium 測試 320／360／390／430／768px 直式及 844px 觸控橫式的音樂控制列；直式底列五項的開啟、切換、再次收合與必要存檔決策限制均通過。測試滑鼠與觸控拖曳 YT 縮小列、置底、鍵盤出現時的預留空間及關閉釋放空間；以同一個 iframe 的載入次數確認縮小、拖曳與置底不會重載影片。貓咪以地面及跳台位置各模擬睡眠 180 秒，確認睡前動作能完成，喚醒不呼叫隨機換位。前述音樂、禮物、訊息、故事回顧與跳台回歸檢查亦通過。這些是本機瀏覽器與模擬測試，未替代實體 Android Firefox、正式 Google 登入或 YouTube 網路播放驗收。
