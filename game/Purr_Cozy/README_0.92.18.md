# Purr Cozy 0.92.18 — 高清家具試用與 CRC32 局部更新

覆蓋 0.92.17。保留其他檔案與音樂。最後上傳 version.json。

## 高清試用
三款既有家具：原木茶几（tb_coffee_oak）、抹茶沙發（sofa_mint）、龜背芋（plant_monstera）。請在商店搜尋並擺放。沒有自動改擺設，也沒有贈送或扣除任何家具。
素材位於 assets/png/hd/furniture-atlas.png；三件高清圖共用透明 PNG 圖集，區域定義見 furniture-regions.json，可在 Godot 建成 AtlasTexture。試用程式亦使用相同區域。
主畫布改依實際顯示寬度與 devicePixelRatio 配置，最大寬 4096，維持原房間比例與擺放座標。人物、貓咪、既有家具及背景維持像素呈現；這次只有三件高清家具，沒有把全部素材重畫。背景原圖仍低解析，不會因畫布變大而憑空變清楚。
網址加 ?hdFurniture=0 可暫時關閉三件替換，方便比較；預設開啟。這是材質試作，沙發坐點、茶几承載面仍沿用原有數據，手繪透視與遮擋需要你進房擺放確認，未聲稱已完成所有坐姿像素對齊。高清圖集不應直接覆蓋原本低解析圖。

## 更新工具
修改任何正式遊戲檔案後，雙擊 Update-Game.cmd（需 Python 3），工具逐檔計算 CRC32 與大小，重建 resources.json，並把總 checksum 寫入 version.json。原有 Rebuild-Resources.cmd 也會呼叫同一工具。
所有正式 JS/CSS/JSON/圖片/字型/音樂/歌詞均掃描；docs、tools、godot、開發暫存與自我參照的 version/resources 檔案排除。
上傳修改的檔案與 resources.json，最後上傳 version.json。修圖不必改遊戲版號，但一定要跑工具並上傳兩份清單資料；這與 0.92.17「只上傳 PNG」不同，因為現在要省下啟動逐檔檢查。
總 checksum 相同：讀本機清單與素材；不同：取得清單，只下載 CRC32 不同或缺失的檔案。不同遊戲版號仍可共用內容未變的快取。新下載會核對 CRC32 與大小。更新失敗不啟用半套版本；已成功下載部分保留供下次續用。瀏覽器清除或回收快取後會重新下載。
CRC32 用於辨識一般檔案變動，不是安全防偽用途。舊 SHA-256 與 resources.bin 不使用。
本版第一次轉到 CRC 快取會下載一次；之後才享有增量效果。仍先完整準備清單內素材，再等雲端存檔，不改為半套資源進房。
Loading 總時間至少 3 秒，載入若已超過 3 秒不追加等待。
