# Purr Cozy 0.92.11 更新說明

適用 0.92.10。請將本包的檔案依原路徑合併覆蓋到遊戲資料夾，包含新增的 js/typo-sound.js 與 assets/cats-typo/meow.wav；不要刪除原本資料夾。這是相關檔案更新包，沒有附整個遊戲的素材、音樂或設定。

## 停用按鈕

修正共用樣式把停用按鈕改為完全不透明、保留黃色主要按鈕配色的問題。每日任務「全部完成獎勵」、未解鎖的寵物訓練與其他停用操作，均改為清楚的灰色無效狀態。保留原本的領獎條件：個別任務獎勵全部領取後，才可領取全部完成獎勵。訓練按鈕也會依生病、受傷、精力不足或心情不足等既有條件停用。測驗選項的答對／答錯色彩仍保留。

## Meow Typo

- 實體鍵盤、貼上與遊戲鍵盤輸入會有短促的打字音效；貓咪按下鍵盤加入錯字時會播放合成貓叫。
- 每題出題時，以及拼字答對後，都透過原本的 SpeechSynthesis 念出英文單字。沒有新增或使用單字 MP3。
- 答對後至少停留兩秒再自動換題；若當次發音還在播放，短暫等待它結束，最多等待至六秒，避免截斷長單字。
- 修正開啟別的視窗後，Meow Typo 模式未解除的狀態；桌機再次點回該視窗可繼續練習。
- 開始頁、完成頁與頁首加入不透明的文字卡片，背景木紋橫線不再穿過文字。說明改為靠左排列，整理字級、行距與段距；手機保持可讀字級，短畫面可捲動。
- 完成統計使用完整的多語言句子；每日任務與自由練習顯示各自的說明與返回入口。

音效沿用目前設定中的 chime 音效開關。打字聲使用 Web Audio 即時合成；貓叫是本次原創合成的 0.68 秒 WAV，已附在包內，不需要外連音效網站，也沒有第三方錄音授權限制。

## 測驗期間音樂音量

進入一般測驗的答題階段或 Meow Typo 練習後，音樂降為玩家設定音量的 70%，並維持至整段測驗完成或離開。單字發音時再套用原本四分之一音量的設計，發音結束後回到測驗的 70%，而不是直接跳回全音量。

例如設定音量 80%：測驗中 56%，念單字時 14%，念完回 56%，離開測驗回 80%。途中若調整音量，結束後恢復的是新的設定值。房間夜間淡出、換歌與 YouTube 的音量調整也使用相同的計算，暫時降低不會改寫玩家儲存的音量。

## 寵物玩具與動作

- 球、毛線球、貓薄荷依點擊位置選最近的貓，忽略寵物清單目前選到哪一隻。逗貓棒每次重新點擊也可換到最近的貓；手機以手指實際點下的位置計算，不以為了避開手指而上移顯示的羽毛位置計算。最近的貓若忙於如廁等動作，不會被強行中斷，也不會偷偷改由遠處的貓使用。
- 點擊貓咪開始梳毛，可看見刷子在身上往返、毛屑與完成反應；放開滑鼠或手指仍會完成。原有的左右輕刷仍可使用，熟悉操作的玩家可加快動作。完成才計入一次清潔與獎勵，原本 20 分鐘的梳毛冷卻不變。中途換工具會安全取消，避免貓咪卡住。
- 如廁包含走近、進入、撥砂、蹲下、覆砂、離開。三種貓砂盆均適用；有罩子的貓砂盆會依入口與前緣遮擋貓的身體。完成才增加一次使用量，降低膀胱需求並依原規則調整清潔度。
- 貓砂盆區分乾淨、已使用與滿載外觀。砂面會變髒、出現結塊，滿載另顯示醒目標記；清理後立即恢復乾淨圖像。使用中的貓砂盆會保留給該隻貓，移走物件或中斷時會解除保留，避免卡死。

## 驗證範圍與限制

已通過 50 項行為與介面檢查，包含灰色停用狀態、打字聲事件、貓叫 WAV 原生解碼、英文發音呼叫、音量 70%／四分之一疊加、連續發音的舊事件不干擾新事件、視窗切換、觸控最近目標、梳毛計次與取消、三種貓砂盆的五階段動畫、滿載圖像、清理與安全中斷，以及繁體／簡體／日文的窄螢幕排版。所有 JavaScript 均通過語法檢查，未捕捉到未處理的頁面 JavaScript 錯誤。

介面與互動使用 Chromium 檢查，手機為 320×600、320×360、390×700 視窗模擬。音量數值使用原生 HTMLAudioElement 驗證；YouTube 驗證的是播放器 setVolume 呼叫，沒有以登入帳號實播測試。此測試環境的 SpeechSynthesis 後端未能實際發聲，因此確認的是英文語言、出題／答對的呼叫與時序；發音仍沿用你已確認在 Firefox 正常的原引擎，沒有更換。沒有把這些檢查稱作 Firefox／iPhone 實機測試。

單字釋義檔沒有變更，保留 0.92.10 已完成的翻譯修訂。既有存檔、寵物、道具與任務紀錄不會重設。版本號仍只由 version.json 提供，更新後應顯示 0.92.11。
