# 台灣國小・國中・高中英文單字總表（2026）報告

> 配套資料檔：`tw_english_vocab_elem_to_high_2026.json`（6,924 筆）。在 Purr Cozy 專案裡是 `tools/vocab.json`，遊戲用的 `i18n/vocab.json` 和 `js/vocab.js` 都由它產生（`python tools/build-vocab.py`）。
> 版本：Purr Cozy 0.92.45（2026/11/06）

## 1. 這份總表收了什麼

| 學程 | 來源 | 字數 |
|---|---|---|
| 國小、國中 | 108 課綱英語文附錄五「參考字彙表 2,000 字」（基本 1,200 字＋其他常用 800 字），2026 年仍沿用 | 2,005 筆 |
| 高中 | Purr Cozy 原有題庫：大考中心「高中英文參考詞彙表」Level 1–6（學測考 Level 1–4，分科考 Level 1–6） | 6,864 個詞條 |
| **合併、去除重複後** | | **6,924 筆** |

國中小 2,000 字裡有 1,945 筆本來就在大考的表裡，所以合併後只多出 **60 個新字**。這 60 個字已補進 Purr Cozy。其中有不少很基本的字，例如 *should, could, birthday, classroom, hi, Taiwan, ice cream, impossible*。大考的表通常不列複合字、衍生字和片語，所以原本漏掉了它們。

## 2. 整理了哪些問題

| 問題 | 原狀況 | 處理方式 | 筆數 |
|---|---|---|---|
| **一字多筆** | 遊戲原始資料有 8,386 列，同一個字依詞性重複出現（例如 *aid* 有 4 列） | 合併成一個詞條，詞性也合併 | 1,238 個字 |
| **詞性寫法不一** | `n. [C]`、`vi. vt.`、`pronoun`、`v. (aux.)` 等寫法混在一起，導致出題時同詞性干擾選項配錯 | 統一成 n. / v. / adj. …，原寫法保留在 `pos_raw` | 全部 |
| **主要詞義遺漏或錯誤** | 原資料常保留次要詞性的意思。例如 *book* 只有「預訂」、*toy* 只有「玩弄；調情」、*car* 是「電梯的升降廂」、*bye* 是「體育比賽中輪空」、*sign* 甚至混進亂碼 | 人工修正，zh-TW 和 ja 一起改，zh-CN 由程式轉換 | 98 筆 |
| **中譯和詞典說法不一致的高中字** | 597 筆和詞典主要義項完全不重疊。有的只是說法不同（*dad*「父親」），有的漏了主要意思（*caterpillar* 只有「履帶牽引車」、*mushroom* 只有「雨後春筍般地湧現」、*post* 只有「布告」） | 逐筆和詞典比對後整合：同義說法併在一起（「爸爸；父親」）；漏掉的主要意思補在最前面，ja 也一起補 | 595 筆整合，2 筆（*teen*、*roach*）確認原本就正確 |
| **詞條混寫** | `O.K. / OK`、`a.m. / am / A.M. / AM`、`afterward(s)` 等 | 改成乾淨的詞條，其他寫法列入 `variants`；遊戲存檔會自動跟著搬移 | 8 筆 |
| **缺音標** | 月份、星期縮寫、`TV`、`MRT`、`e-mail` 等 30 筆沒有音標 | 補上 KK 音標 | 30 筆 |
| **國中小新字** | 遊戲沒收 | 人工撰寫 zh-TW 和 ja 中譯，zh-CN 由程式轉換；音標、年級、難度都補齊 | 60 筆 |

## 3. 每筆有哪些欄位

| 欄位 | 內容 | 完整度 |
|---|---|---|
| `zh`、`translations` | 精簡中譯，三種語言（zh-TW / zh-CN / ja） | 6,924 / 6,924 |
| `pos` / `pos_zh` | 所有詞性；一字多詞性的有 2,137 筆 | 全部 |
| `meanings` | 各詞性的詳細中譯（國中小字經人工校訂，高中字取自 ECDICT） | 6,873 |
| `phonetic.kk` | 台灣 KK 音標，沿用遊戲原有寫法（ˋ 主重音、͵ 次重音） | 6,924 |
| `phonetic.ipa_us` / `ipa_uk` | 美式、英式 IPA | 6,859 / 6,790 |
| `forms` | 過去式、過去分詞、現在分詞、三單、複數、比較級、最高級 | 5,425（其餘是沒有變化的詞性） |
| `stage` / `grade_num` / `grade_estimate` | 學程和建議年級 | 全部 |
| `difficulty` | 1–5 難度（定義見下方） | 全部 |
| `lists` | 課綱 2000 字分類、大考 Level | 全部 |
| `frequency_rank` / `oxford3000` / `collins_stars` | 字頻排名和國際常用字標記 | 大部分 |
| `topics` / `related_in_list` | 課綱主題分類、衍生字 | 國中小字 |
| `purr_cozy` | 遊戲裡的固定索引、Level、適性難度、音檔名、改名前的詞條 | 全部 |
| `quality_flags` | 品質標記 | — |

| | | 高三（大考 Level 5–6） | 2,391 |

年級是**估計值**，判斷方式如下：

- **國小**：依各版本教科書常見主題人工挑選。
- **國中**：依字頻切分。
- **高中**：依大考 Level 對應。

大考 Level 1–2 的字，大部分已經在國中小 2,000 字裡，所以真正歸到「高一」的只有 497 個。

## 5. 使用提醒

- **全部 6,924 筆都已處理完畢，沒有待人工複查的項目**。`quality_flags` 的意義如下：
  - `meaning_fixed`：693 筆，中譯已修正或整合。
  - `meaning_checked`：2 筆，已比對過，原本的中譯正確。
  - `new_in_purr_cozy`：60 筆，新加入遊戲的字。
  - `phonetic_added`：30 筆，補上了音標。
  - `headword_normalized`：8 筆，詞條寫法已整理。
- **高中字的詳細中譯**：`meanings` 取自詞典，冷門義項可能排在前面。遊戲出題用的是精簡中譯 `zh` 和三語 `translations`，這兩個都已校對過。
- **中譯裡的英文註記**：大約 60 筆中譯帶有英文說明，例如 *photograph* 的「照片（= photo）」。資料保留原樣，遊戲出題時會自動拿掉，避免洩漏答案。
- **之後要改單字**：直接改 `tools/vocab.json`，然後依序執行 `python tools/build-vocab.py` 和 `Update-Game.cmd`。新字要用下一個空著的 `purr_cozy.index`，不可以重新排序。
