## 0. 怎麼讀這份文件

**用詞**

- **必須**：照做才算實作了 mac model v3.1。
- **應該**：建議做法；不照做要有理由。
- **可以**：選用。
- **提案**：本文件提出、但還沒有在任何實驗室或產品中實作與驗證的做法。

**數字的身分標記**：每個關鍵數字後面都有一個標記，方便人和程式搜尋。

| 標記 | 意思 | 上線後怎麼處理 |
| --- | --- | --- |
| `[文獻]` | 已發表研究的實測值，多半測自美國或菲律賓學生 | 可先沿用，但要用自己的族群資料確認 |
| `[推導]` | 由文獻數字或公式算出 | 前提改變時要重算 |
| `[假設]` | 設計選擇，沒有實測依據 | 最先用自己的資料校準 |
| `[模擬]` | 本團隊在模擬學習者上跑出的結果，學習者完全照模型行動 | 只代表最理想的情況，不是真實學生的表現 |

**本文件的數字來源**：本文件與 NOUS 學習者模型頁面、程度反推實驗室、把握校準實驗室、情意狀態實驗室（2026-11-07 版）的公式、參數與數字完全對齊；任何一處修改，五份文件必須一起改。第 12 節的測試數值在 2026-11-07 用獨立的 Python 程式和實驗室原始碼重算過，結果一致。

**版本**：v3.1（2026-11-07）只修正 v3.0 文件的不完整之處：5.2 的 Q 改印 6 位小數，5.2 與 A10 註明原因（14.2 第 16 項）。模型的公式、參數、T 與所有測試數值都和 v3.0 相同，按 v3.0 寫成的實作不必修改。

**本文件不包含**：任何產品的角色、劇情或介面。mac model 只回答「學習者現在是什麼狀態」與「哪一種行動的依據比較充分」，要用哪個角色、哪句台詞去執行，是接入產品的事（NOUS 的接法見附錄 A，呼嚕小窩的接法見附錄 B）。

## 1. 總覽

學習者的真實狀態看不到，mac model 只能從觀察推估。每個學習事件都走同一個迴圈：

```
觀察（對錯、作答時間、提示、把握、推動後的反應）
  → 預測：依經過的時間，把每個子模型往前推一步
  → 更新：用這次觀察修正（貝氏定理）
  → 決策輸出：下一題、要不要介入、該複習什麼
  → 產品執行（出題、講解、追問、陪伴）→ 下一次觀察
```

**狀態 X = (m, a, c)，加上兩種記憶**

| 子模型 | 回答的問題 | 主要觀測 | 時間尺度 | 狀態型態 | 第幾節 |
| --- | --- | --- | --- | --- | --- |
| m 精熟度 | 他會什麼？ | 對錯 | 數天到數週 | K 維能力 θ 的機率分佈 | 4 |
| a_fast 此刻情意 | 他現在投入嗎？ | 作答行為 | 數分鐘 | 4 個離散狀態的機率 | 5 |
| a_slow 偏好的推動方式 | 什麼方式推得動他？ | 推動後接不接得住 | 數週 | 6 組 Beta 計數 | 6 |
| c 後設認知校準 | 他對自己的判斷準嗎？ | 作答前的把握＋對錯 | 數週到數月 | 兩個參數 (κ, β) 的機率分佈 | 7 |
| 學習者的記憶 | 他還記得多少？ | 複習時想不想得起來 | 數天到數月 | 每個知識點一個穩定度 S_k | 8 |
| 系統對學習者的記憶 | 產品記得他哪些事？ | 對話與互動紀錄 | 跨學期 | 三層：Working、Episodic、Profile Memory | 9 |

**三個設計原則**

1. **每個估計都記「平均」和「寬度」**。寬度讓模型分得清「不會」和「還不知道會不會」。實作必須保留完整的後驗分佈（格點或粒子），不能只存一個點估計。
2. **同一套數學**：m、a、c 都是「預測 → 更新」的貝氏濾波，只是狀態空間、觀測和時間尺度不同。
3. **獎勵只跟可驗證的學習證據走**：產品中的成長、解鎖、獎勵，應該只隨精熟度上升 Δm 與延遲後仍答得出來而改變，不隨登入時數或點擊次數改變。mac model 會輸出 Δm 供產品使用。

## 2. 名詞與記號

| 記號 | 意思 | 範圍或預設 |
| --- | --- | --- |
| θ | 學習者能力，K 維向量，θ_d 是第 d 個維度 | 先驗 N(0, I) |
| d | θ 的維度，例如「文」「理」，或每個知識點各一維 | K 個 |
| k | 知識點，記憶模型的單位 | 每題屬於一個知識點 |
| w | 題目的載荷向量，表示這題考哪些維度 | ‖w‖ = 1 |
| a | 題目鑑別度（曲線多陡） | 0.8～2.0 |
| b | 題目難度 | −2.5～2.5 |
| g | 猜對率（不會也答對的機率） | 四選一 0.25、是非 0.5、填答 0 |
| s | 粗心率（會也答錯的機率） | 0.10；填答 0.05 |
| σ(x) | 1 / (1 + e^−x)，logistic 函數 | |
| logit(p) | ln[p / (1 − p)]，σ 的反函數，也就是 log 勝算 | |
| y | 作答結果，1 = 對，0 = 錯 | |
| ℓ | 一次講解後，從「不會」變「會」的機率 | 0.20 `[假設]` |
| Q | a_fast 的轉移速率（連續時間，每分鐘） | 4 × 4，見 5.2 |
| T | a_fast 的一分鐘轉移矩陣，T = e^Q | 4 × 4 |
| B | a_fast 的觀測矩陣 | 4 × 5 |
| π | a_fast 的穩態分佈 | (0.831, 0.071, 0.049, 0.049)；計算時用 (0.8306, 0.0708, 0.0495, 0.0491) |

| q | 學習者作答前說的把握 | {0.25, 0.50, 0.75, 0.95} |

## 3. 資料結構

以下 JSON 是建議格式。欄位名可以改，但每個欄位代表的東西必須都有。

### 3.1 題目 Item

```json
{
  "item_id": "phys-newton2-017",
  "knowledge_point": "kp_newton2",
  "w": [0.0, 1.0],
  "a_disc": 1.5,
  "b": 0.0,
  "g": 0.25,
  "s": 0.10,
  "format": "mc4",
  "mean_rt_ms": 21000,
  "purpose_ok": ["diagnostic", "practice", "review"]
}
```

- `w` 的維度順序由全域設定 `dims`（例如 `["wen", "li"]`）決定。純文題 (1, 0)、純理題 (0, 1)、綜合題 (√½, √½) ≈ (0.7071, 0.7071)，長度剛好為 1。
- `format` 決定 g、s 的預設：`tf` 是非 g 0.5 s 0.1；`mc4` 四選一 g 0.25 s 0.1；`fill` 填答 g 0 s 0.05。
- `mean_rt_ms` 是這題所有人作答時間的平均，用來判斷快速亂猜。題目剛上線還沒有資料時，可以先用同類題的平均。

### 3.2 學習事件 Event

產品每發生一件事，就送一個事件給 mac model。mac model 必須按時間順序處理事件。

```json
{
  "event_id": "e-000123",
  "learner_id": "u-42",
  "t": "2026-11-07T10:15:30+08:00",
  "type": "response",
  "item_id": "phys-newton2-017",
  "correct": 0,
  "rt_ms": 1800,
  "hints_used": 0,
  "pause_before_ms": 6200,
  "confidence_q": 0.75,
  "purpose": "practice"
}
```

| type | 何時送 | 必要欄位 |
| --- | --- | --- |
| `session_start` | 開始一段學習 | t |
| `response` | 每次作答 | item_id、correct、rt_ms、hints_used、pause_before_ms；有問把握時加 confidence_q |
| `instruction` | 講解了一個知識點（沒有作答） | knowledge_point |
| `nudge_outcome` | 用某種推動方式推了一次之後，結果明確時 | style、caught（true／false） |
| `session_end` | 結束 | t |

## 4. m：精熟度

### 4.1 作答模型

$$
P(y = 1 \mid \theta) = g + (1 - g - s)\,\sigma\!\big(a\,(w \cdot \theta - b)\big)
$$

- 曲線下限是 g（不會也可能猜對），上限是 1 − s（會也可能粗心）。
- θ 在 w 方向上的投影等於 b 時，答對率 = g + (1 − g − s)/2。四選一、s = 0.1 時是 0.575。
- σ 的形狀和 Fermi 分佈相同：w·θ − b 像能量差，a 像逆溫度。

**兩個特例**

| 特例 | K | w | 用途 |
| --- | --- | --- | --- |
| 每個知識點各一維 | 知識點數 | one-hot，只在自己的知識點上是 1 | 知識點之間不互相借資訊；每維可以獨立做 1D 濾波 |
| 文／理兩維 | 2 | 文 (1, 0)、理 (0, 1)、綜合 (√½, √½) | 程度反推實驗室的設定；第 4.8 節的模擬數字都來自這個設定 |

**題庫必須讓每個維度都有專屬題**。只用綜合題時，模型只能看到 θ_文 + θ_理，永遠分不出偏文還是偏理：模擬中全部用綜合題時，沒有任何學習者能把兩維的 SD 都降到 0.5 `[模擬]`。

### 4.2 證據強度：用勝算看一題值多少

把「會」與「不會」簡化成兩態時，會的人答對機率 1 − s，不會的人答對機率 g：

$$
\text{後驗勝算} = \text{先驗勝算} \times \frac{P(y \mid \text{會})}{P(y \mid \text{不會})}
$$

| 情況（g 0.25、s 0.10） | 證據強度 |
| --- | --- |
| 答對 | 勝算 × (1 − s)/g = × 3.6 |
| 答錯 | 勝算 ÷ (1 − g)/s = ÷ 7.5 |
| 答錯，但 s 調高到 0.3（見 4.6） | 勝算 ÷ 2.5 |

兩個直接的推論：**答錯的力道比答對大**（會的人很少答錯，不會的人不算少猜對），以及 **g 越大，答對越不值錢**（四選一單獨答對一題，不足以證明學會）。

### 4.3 濾波

每一輪兩步：

$$
\text{預測：}\; P(\theta_t \mid y_{1:t-1}) = \int P(\theta_t \mid \theta_{t-1})\, P(\theta_{t-1} \mid y_{1:t-1})\, d\theta_{t-1}
$$

$$
\text{更新：}\; P(\theta_t \mid y_{1:t}) \propto P(y_t \mid \theta_t)\, P(\theta_t \mid y_{1:t-1})
$$

**表示法**

| K | 做法 | 參數 | 狀態 |
| --- | --- | --- | --- |
| 1 或 2 | 格點 | 每維 81 點，範圍 [−4, 4]（顯示與單人推估）；大量模擬可用 41 點 | 已實作（程度反推實驗室） |
| 3 以上，或知識點互相關聯 | 粒子濾波：一群樣本代表分佈，依作答調整權重，有效樣本數太低時重新抽樣 | 粒子數、重抽門檻未定 | 未實作 |

更新步必須是「乘上似然、再歸一化」：答對乘 P，答錯乘 1 − P。先驗必須是 N(0, I)，除非有冷啟動資料（4.7）。

### 4.4 預測步：學習與遺忘

v3.1 只在兩態版本定義了預測步：

- **講解**（`instruction` 事件）：P(會) ← P(會) + P(不會) × ℓ，ℓ = 0.20 `[假設]`。會的人繼續會；不會的人有 ℓ 的機率學會。
- **兩次練習之間**：交給第 8 節的記憶模型。

連續 θ 的預測步（講解讓分佈往哪移、移多少）**v3.1 沒有定義**。在定義之前，實作應該把 θ 視為兩次講解之間不變，並把遺忘放在 R_k（8.4 的提案）。

### 4.5 不能拿來更新 m 的作答

- **快速亂猜**：作答時間低於該題平均作答時間的 10%（NT10），答對率約等於隨機 `[文獻]`。這題必須不更新 m（但要送進 a_fast，見第 5 節）。
- 產品自己判定為無效的作答（例如呼嚕小窩中貓咪插入字母造成的錯），也應該不更新 m。

### 4.6 a 影響 m：調高粗心率

a_fast 判斷學習者不在狀態時，應該把這題的 s 從 0.10 調到 0.30 `[假設]`，答錯的證據強度就從 ÷7.5 降到 ÷2.5，m 不會因為一次分心被誤判成不會。

**觸發條件**（2026-11-07 定案）：這題作答前 a_fast 更新後的 P(無聊) ≥ 20% 時，s 必須用 0.30；否則用題目自己的 s。20% 沿用低代價門檻 `[假設]`。

為什麼是這條：原始規則寫「疲倦或亂猜」，但 a_fast 的四個狀態裡已經沒有「疲倦」（早期草稿的疲倦改成了無聊），而快速亂猜已經依 4.5 不更新 m，所以剩下要處理的就是「人在但心不在」的無聊。

### 4.7 選題

**診斷題**（目的是盡快知道程度）：選讓後驗最窄的題目，也就是 D-optimal：

$$
k^* = \arg\max_k \det\!\big(\Sigma^{-1} + f_k(\hat\theta)\, w_k w_k^{\top}\big)
$$

$$
f_k(\theta) = \frac{\big[(1-g-s)\,a\,\sigma(u)(1-\sigma(u))\big]^2}{P(1-P)},\quad u = a(w\cdot\theta - b)
$$

- Σ 是目前後驗的共變異數，θ̂ 是後驗平均。已經出過的題不再選。
- 經驗法則：這相當於挑答對率約 50% 的題 `[推導]`。有猜對率時資訊量最大的點略高於 50%，用上式就會自動處理，不必另外調。

**練習題**：選「後驗平均答對機率」最接近目標的題，起始目標 85% `[假設]`：

$$
\bar P_k = \int P(y = 1 \mid \theta)\, P(\theta \mid y_{1:t})\, d\theta
$$

85% 法則的原始推導針對特定學習模型，作者自己限縮在知覺學習 `[文獻]`，所以 85% 只是起點，必須用自己的資料校準。

**停止規則**（診斷）：每個維度的後驗 SD 都 ≤ 0.5 `[假設]`，或題庫用完。

**冷啟動**：新的學習者先做一段診斷題，標定 m(0)。

### 4.8 需要幾題：模擬結果

設定 `[模擬]`：300 位學習者，真實 θ ~ N(0, I)；題庫 100 題（文 40、理 40、綜合 20），b 在 ±2.5 間分層均勻，a 在 0.8～2.0 間均勻，四選一 g 0.25 s 0.1；41 × 41 格點；停在兩維 SD 都 ≤ 0.5。

統計量的定義：**中位數**把 300 位都算進去，題庫用完仍未停下的人記為無限大（所以未停下的人超過一半時，中位數寫「—」，表示超過題庫題數）；**能停下的比例** = 在題庫用完前停下的人數 ÷ 300。

| 情境 | 自適應：中位數 | 隨機出題：中位數 | 能停下的比例（自適應／隨機） |
| --- | --- | --- | --- |
| 預設題庫 | 43 題 | 85 題 | 90% ／ 83% |
| 題庫 150 題 | 35 | 81 | 100% ／ 100% |
| 鑑別度高（a 1.5～2.5） | 25 | 62 | 100% ／ 97% |
| 填答題（g 0、s 0.05） | 13 | 35 | 100% ／ 100% |
| 目標放寬到 SD 0.6 | 21 | 52 | 100% ／ 99% |
| 目標收緊到 SD 0.4 | — | — | 約 3%（自適應） |
| 是非題、40 題題庫、低鑑別度（a 0.4～0.8）、全部綜合題，任一種 | — | — | 0%（是非題 0.3%，即 300 人中 1 人） |

讀法：自適應選題約省一半題數；題目的形式（填答 vs 選擇）和鑑別度，比題庫大小影響更大。

### 4.9 m 的輸出

- 每維的後驗平均、SD、維度間相關。
- 象限機率（例如 P(θ_文 > 0 且 θ_理 > 0)），給產品做粗分類。
- Δm：一段期間前後的後驗平均差，以及這個差是否大於兩端 SD 的合成值（是否可信）。

## 5. a_fast：此刻的情意狀態

### 5.1 狀態與觀測

四個狀態沿用學習情緒研究的標準四態 `[文獻]`：**投入、困惑、挫折、無聊**。

每一題（或每一分鐘）mac model 必須把作答歸入**一種**行為：

| 行為 | 定義 | 數值是否已定 |
| --- | --- | --- |
| 正常 | 不屬於以下任何一種 | — |
| 卡住 | 連錯兩次後停超過 5 秒，或要提示 | 已定 |
| 弱項答錯 | 這個技能過去錯誤率高，又答錯 | 「錯誤率高」的門檻未定 |
| 變慢 | 平均反應時間明顯變長 | 「明顯」的門檻未定 |
| 快速亂猜 | 作答時間低於該題平均的 10%（NT10） | 已定 `[文獻]` |

同一題符合多種行為時，依這個順序取第一個：快速亂猜 > 卡住 > 弱項答錯 > 變慢 > 正常 `[假設]`。「弱項答錯」與「變慢」的數值門檻要等試點資料，先用分位數訂（第 13 節）。學習者模型頁面與情意狀態實驗室用的是同一套定義與順序。

### 5.2 兩個矩陣

**轉移速率 Q**（連續時間，每分鐘；列是「從」，欄是「到」）。這是 a_fast 的定義參數，印到小數 6 位：

```
          投入        困惑        挫折        無聊
投入    −0.114700    0.084614    0.028728    0.001357
困惑     0.927923   −1.039721    0.055899    0.055899
挫折     0.491020    0.041411   −0.562011    0.029580
無聊     0.113904    0.009606    0.006862   −0.130373
```

Q 必須用 6 位小數（或依下面的建法直接算出、不取位）。若把 Q 再取到 4 位小數，e^Q 的第 4 列（無聊）用最大餘數法會得到 (0.106, 0.009, 0.007, 0.878)，和下面的 T 差 0.001：該列投入與挫折兩格的捨去部分很接近，Q 少幾位就足以讓 0.001 補給錯的格子。

**一分鐘轉移矩陣 T = e^Q**（每步 = 1 分鐘，約一題）。實驗室與頁面的程式都直接用這個取位後的 T，不在程式中計算 e^Q，所以 Q 的位數不影響任何模擬數字。T 取到小數 3 位、每列加總為 1。取位的方法是最大餘數法：每列先把四個元素都無條件捨去到小數 3 位，該列還差幾個 0.001，就依捨去部分由大到小，各加 0.001 給那幾個元素。直接四捨五入會有 3 格差 0.001，每列也不一定加總為 1：

```
          投入    困惑    挫折    無聊
投入     0.924   0.051   0.022   0.003
困惑     0.558   0.374   0.034   0.034
挫折     0.371   0.031   0.576   0.022
無聊     0.107   0.009   0.006   0.878
```

Q 的建法：

| 依據 | 投入 | 困惑 | 挫折 | 無聊 |
| --- | --- | --- | --- | --- |
| 半衰期（秒），實測 `[文獻]` | 260 | 40 | 74 | 319 |
| 半衰期（秒），模型 `[推導]` | 363 | 40 | 74 | 319 |
| 出現比例 `[文獻]` | 83% | 7% | 5% | 5% |
| 穩態（驗算，用上面的 T）`[推導]` | 0.831 | 0.071 | 0.049 | 0.049 |

- 困惑、挫折、無聊離開的速率由半衰期換算：λᵢ = ln 2 ÷ 半衰期 `[推導]`。模型中這三個狀態的半衰期與實測完全相同。
- 離開某狀態後，依目的地的出現比例分配：qᵢⱼ = λᵢ πⱼ ÷ (1 − πᵢ)。12 個資料集的再分析找不到穩定的特定轉移路徑 `[文獻]`，所以用「隨機」當預設。
- 投入那一列由穩態平衡決定，讓長期比例回到 83 / 7 / 5 / 5% `[推導]`。
- 半衰期與出現比例測自美國中學數學輔導系統，觀察員每 20 秒標註一次。

**T 的對角線不是半衰期**：T_ii 是「一分鐘後仍在這個狀態」的機率，包括中途離開又回來的人，所以不能用 0.5^(60/半衰期) 互相換算。半衰期必須從 Q 的對角線算：半衰期 = ln 2 ÷ (−Q_ii)。以前的版本直接在一分鐘的步長上建 T，再從投入的對角線反推，得到約 526 秒（9 分鐘），那是這個誤用造成的。

**投入的半衰期為什麼是 363 秒而不是 260 秒**：在任何馬可夫模型中，長期來看流出投入的量必須等於流入投入的量。流入最多的情況，是困惑、挫折、無聊離開時全部回到投入，這時投入的半衰期至少要 321 秒 `[推導]`。所以「投入 260 秒」和「83 / 7 / 5 / 5% 的比例、其他三個半衰期」不可能同時被任何馬可夫模型滿足，差距來自資料本身，不是建法的問題。最可能的原因是投入片段的長度不是指數分佈：短片段很多、少數很長，中位數短、平均長，而出現比例取決於平均。v3.0 的決定：保留三個非投入狀態的半衰期和四個出現比例，投入的半衰期由模型推得 363 秒。試點時應該直接量投入片段長度的分佈（第 13 節）。

**觀測矩陣 B**（列加總為 1，欄不必）：

```
          正常   卡住   弱項答錯   變慢    快速亂猜
投入     0.78   0.06   0.06      0.06    0.04
困惑     0.48   0.36   0.06      0.06    0.04
挫折     0.54   0.06   0.30      0.06    0.04
無聊     0.64   0.06   0.06      0.144   0.096
```

- 行為與狀態的對應、快速亂猜歸給無聊而不是挫折 `[文獻]`。
- 訊號倍數：困惑的「卡住」× 6、挫折的「弱項答錯」× 5、無聊的「變慢」與「快速亂猜」× 2.4 `[推導]`。這是把濾波的分辨力校到 AUC 約 0.70。用上面的 T 重算的每分鐘 AUC：困惑 0.70、挫折 0.70、無聊 0.71 `[模擬]`。校正前（每個訊號 × 2）只有 0.54、0.55、0.66。
- 為什麼對齊到 0.70：只用作答紀錄的偵測器，公開數字如下 `[文獻]`。早期的特徵工程偵測器平均 AUC 0.65～0.66；LSTM 偵測器的逐狀態 AUC 是困惑 0.72、挫折 0.76、無聊 0.80、投入 0.80（Botelho, Baker & Heffernan 2017，未重抽樣版本）；同一團隊 2018 年重新擬合後平均 0.74。mac model 只用五類粗略行為，資訊比 LSTM 的特徵少很多，所以目標定在 0.70：高於早期偵測器，低於 LSTM 的每一個狀態 `[假設]`。
- 0.06、0.04 這些基本出現頻率 `[假設]`，上線後第一個要校準。

### 5.3 濾波

$$
\text{預測：}\; P(a_t = j) = \sum_i P(a_{t-1} = i)\, T_{ij}
$$

$$
\text{更新：}\; P(a_t = j \mid o_t) \propto B_{j,\,o_t}\, P(a_t = j)
$$

- `session_start` 時，P 必須重設為穩態 π。
- 兩題相隔不是 1 分鐘時，必須用 T(Δt) = e^(QΔt)，Δt 以分鐘計（矩陣指數，例如 scipy.linalg.expm）。結果一定是合法的轉移矩陣，不會有負的元素。第 12 節有 30 秒與 2 分鐘的數值。
- 相隔超過 30 分鐘時，應該直接視為新的一段，重設為 π。這是 **提案**：T 的穩態本來就是 π，長時間後兩者幾乎相同，重設只是省計算。

### 5.4 介入規則

**門檻公式**：

$$
\text{門檻} = \frac{\text{誤報代價}}{\text{誤報代價} + \text{抓對的好處}}
$$

| 層級 | 門檻 | 代表 | 適合的行動（通用） |
| --- | --- | --- | --- |
| 低代價 | 20% `[假設]` | 抓對的好處是誤報代價的 4 倍 | 換個說法、給一點鼓勵，不打斷學習 |
| 高代價 | 40% `[假設]` | 1.5 倍 | 換任務、請另一個角色出場、降低難度 |

**判斷順序**（每題更新後，由上往下，第一條成立就輸出）`[假設]`：

1. P(無聊) ≥ 40% → 高代價：換一種推動方式，或讓學習者自己選下一步。
2. P(挫折) ≥ 40% → 高代價：降低難度、拆成小步。
3. P(困惑) 連續兩題 ≥ 40% → 高代價：把困惑拆開講。
4. P(無聊) ≥ 20% → 低代價：換一種語氣或包裝。
5. P(挫折) ≥ 20% → 低代價：鼓勵一句，或提供拆小步的選項。
6. P(困惑) 連續兩題 ≥ 20% → 低代價：提示可以要線索。
7. P(困惑) ≥ 20% 但只有一題 → 先等一分鐘，不行動。
8. 以上都不成立 → 維持目前節奏。

規則背後的理由：

- **困惑要連續兩題才算數**：困惑的半衰期只有約 40 秒，多半會自己解開 `[文獻]`。實作上，「連續兩題 ≥ 門檻」就是 min(這題的 P(困惑), 上一題的 P(困惑)) ≥ 門檻。
- **無聊最優先**：無聊最黏（半衰期約 5 分鐘），也最常接著出現亂猜、鑽系統漏洞 `[文獻]`。
- 無聊期間的快速亂猜，不拿來判斷會不會（4.5）。

### 5.5 效果：模擬 40 萬分鐘

設定 `[模擬]`：學習者完全照 T 與 B 行動，每分鐘一個觀測；亂數種子 3（情意狀態實驗室的 mulberry32 產生器），2026-11-07 用新的 T 重算。

| 門檻 | 每 30 分鐘警報 | 抓到：無聊／困惑／挫折 | 警報正確：無聊／困惑／挫折 |
| --- | --- | --- | --- |
| 低代價 20% | 0.9 次 | 21% ／ 8% ／ 19% | 28% ／ 49% ／ 32% |
| 高代價 40% | 0.16 次（約 3 小時一次） | 6% ／ 1% ／ 7% | 52% ／ 63% ／ 49% |

40% 門檻的「困惑警報正確」只建立在約 440 個達到門檻的分鐘上，數字很不穩：模型與設定都不變、只換種子，會在約 57%～67% 之間變動。比對這一格時，請用多組種子的平均，容許範圍放寬到 ±5 個百分點。

定義：

- **警報**：「任一狀態 ≥ 門檻」從不成立變成成立的那一刻（困惑用連續兩題的規則）。
- **抓到**：真實狀態的一段連續期間內，模型至少有一分鐘對這個狀態達到門檻。
- **警報正確**：達到門檻的分鐘中，真實狀態確實是這個狀態的比例。

**結論**：即使在最理想的情況下，兩層都抓不到大多數片段。光靠作答紀錄，a_fast 只適合觸發低代價的調整；要抓得更多，需要更多訊號或試點資料。

### 5.6 限制

- 偵測器的 AUC 以每 20 秒一段計算，mac model 每分鐘（約每題）一個觀測。AUC 不受門檻影響，但取樣單位不同，所以 0.70 只能當同一量級的對照，不是可以直接相比的數字。例如困惑 × 6，等於假設 36% 處於困惑的分鐘會出現「卡住」，這要用試點資料直接驗證（第 13 節）。
- 投入的半衰期：模型 363 秒、實測 260 秒，原因見 5.2。
- 偵測器不能跨族群搬用：在一個族群訓練的偵測器搬到另一族群，A′ 從 0.67 掉到 0.52 `[文獻]`。
- 學習者自我回報（例如「你還好嗎？」的回覆）**不放進 B**：同一研究中自評無聊 32%、觀察員只看到 5% `[文獻]`，沒有可信的數值可用。

## 6. a_slow：偏好的推動方式

### 6.1 模型

六種推動方式：**挑戰、支持、探索、回想、創造、反思**。每一種記兩個數：推動後「接住了」幾次、「沒接住」幾次。

$$
\text{有效估計} = \frac{\alpha}{\alpha + \beta}
$$

- **接住**：接受、做完，或隔天主動回來。**沒接住**：拒絕、中途放棄，或推動後就離開。
- 接住 → α + 1；沒接住 → β + 1。這就是 Beta 分佈的貝氏更新。
- 每週一次，所有計數 × 0.9 `[假設]`，讓舊證據淡出。
- 跨登入保留，以週為單位變化。

### 6.2 先驗

學習者自己選的偏好（例如入門時選的角色或風格）就是先驗：選中的方式 α = 3、β = 1，其他方式 α = β = 1 `[假設]`。這是學習者自己表態的動機與偏好，**不是學習人格或學習特質**，之後依行為修正。

### 6.3 建議換方式的規則

`[假設]`，來自情意狀態實驗室：

- 有某種方式的有效估計比學習者原本選的高 ≥ 0.2，而且那種方式的 α + β ≥ 4（證據夠多），才建議換。
- 建議只能用提議的形式（「要不要換個方式試試？」），決定權必須留給學習者。

範例：原本選挑戰。一週內挑戰推了 4 次只接住 1 次：3/1 → 4/4，75% → 50%。探索推了 3 次都接住：1/1 → 4/1，50% → 80%。差 0.3，探索的 α + β = 5，可以提議。

## 7. c：後設認知校準

c 衡量的是自我認識，不是能力。程度低但老實說「沒把握」的學習者，c 仍然很好。

### 7.1 觀測

部分題目在作答前問「你有多少把握？」，四個選項：

| q | 0.25 | 0.50 | 0.75 | 0.95 |
| --- | --- | --- | --- | --- |
| 建議文字 | 用猜的 | 一半一半 | 大概會 | 很有把握 |
| logit(q) | −1.099 | 0 | 1.099 | 2.944 |

頻率：約四題問一次，集中在驗證題 `[假設]`。不必每題都問。

### 7.2 模型

$$
P(y = 1 \mid q;\, \kappa, \beta) = \sigma\big(\kappa\,\mathrm{logit}(q) + \beta\big) = \frac{e^{\beta} q^{\kappa}}{e^{\beta} q^{\kappa} + (1-q)^{\kappa}}
$$

等價的說法：實際勝算 = e^β × (自稱勝算)^κ。

| 參數 | 意思 |
| --- | --- |
| κ = 1、β = 0 | 完美校準：說幾成把握，就答對幾成（對角線） |
| β < 0 | 過度自信：整條曲線往下沉 |
| β > 0 | 過度保守 |
| 0 < κ < 1 | 把握太極端：有把握和沒把握的實際差距，比他說的小 |
| κ ≈ 0 | 把握沒有資訊 |

**推導** `[推導]`：假設學習者對每題有一個內在證據 E，答對時 E ~ N(+μ, s²)、答錯時 E ~ N(−μ, s²)，兩個高斯相除時 E² 項抵消：

$$
\mathrm{logit}\,P(\text{對} \mid E) = \frac{2\mu}{s^2} E + \ln\frac{\pi}{1-\pi}
$$

學習者用自以為的 μ′、s′、π′ 把 E 換成把握 q。消去 E：

$$
\kappa = \frac{\mu / s^2}{\mu' / s'^2}, \qquad \beta = \ln\frac{\pi}{1-\pi} - \kappa \ln\frac{\pi'}{1-\pi'}
$$

κ 是真實的證據靈敏度除以自以為的靈敏度（用溫度比喻是 T′/T）；β 主要反映對自己整體答對率的誤判。若答對與答錯時的變異數不同，會多一個二次項 γ · logit(q)²，等資料夠多再檢查。

| --- | --- | --- |

### 7.5 需要幾題：模擬結果

設定 `[模擬]`：61 × 61 格點，每種學習者 300 位，四個把握選項等機率使用，停在某區域 ≥ 80%，最多 300 筆把握題。

| 真實類型 | 把握題數中位數 | 第一次判斷就對 |
| --- | --- | --- |

| 無鑑別力 | 33 | 99% |
| 過度保守 | 38 | 100% |
| 校準良好 | 127 | 79% |

約四題問一次把握，所以總作答數約是上表的四倍。學習者多半只說「很有把握」「大概會」時（四選項比例 5／15／40／40%），校準良好要 262 筆。

讀法：有問題的類型很快就看得出來；「沒問題」要最久才能確定，而且第一次判斷有兩成會錯。

### 7.6 c 的用法

- 過度自信（P(β < −0.5) 高）→ 追問：「你確定嗎？換個條件還成立嗎？」
- κ 偏低 → 引導反思：「這題和上一題，哪題比較有把握？為什麼？」
- c 不該被永久定型：校準會隨練習和回饋改善 `[文獻]`，預測步的模糊就是為了這個。

## 8. 學習者的記憶：回想機率與複習排程

### 8.1 模型：採用 FSRS-6

mac model v3.1 的學習者記憶必須採用 FSRS-6（開源的間隔複習排程演算法，Anki 等軟體使用），並以它的 21 個預設參數起步 `[文獻]`。每個知識點 k 記三個量：難度 D_k（1～10）、穩定度 S_k（天，定義為回想機率降到 90% 所需的天數）、上次複習時間。

**回想機率**（冪次律）：

$$
R_k(t) = \left(1 + F\,\frac{t}{S_k}\right)^{-w_{20}}, \qquad F = 0.9^{-1/w_{20}} - 1 \approx 0.9803
$$

**下次複習**：回想機率掉到 R* 的時間

$$
t^* = \frac{S_k}{F}\left(R^{*\,-1/w_{20}} - 1\right) \quad (R^* = 0.9 \text{ 時 } t^* = S_k;\; R^* = 0.8 \text{ 時 } t^* \approx 3.32\, S_k)
$$

**作答怎麼對應到 FSRS 的評分** `[假設]`：答對 → Good（G = 3）；答錯 → Again（G = 1）；快速亂猜 → 不更新（4.5）。v3.1 不使用 Hard（2）與 Easy（4）。

**更新式**（G 是評分，R 是這次作答當下的回想機率 R_k(t)，t 是距上次複習的天數）：

| 時機 | 公式 |
| --- | --- |
| 第一次 | S₀ = w_(G−1)：Good 2.3065 天、Again 0.212 天；D₀(G) = w₄ − e^(w₅(G−1)) + 1：Good 2.118、Again 6.413 |
| 答對 | S′ = S · [1 + e^(w₈) · (11 − D) · S^(−w₉) · (e^(w₁₀(1−R)) − 1)] |
| 答錯 | S′ = min{ w₁₁ · D^(−w₁₂) · [(S + 1)^(w₁₃) − 1] · e^(w₁₄(1−R)) ,  S ÷ e^(w₁₇w₁₈) } |
| 難度 | D′ = D + (10 − D)/9 · [−w₆(G − 3)]；再向 D₀(4) 回歸：D″ = w₇ · D₀(4) + (1 − w₇) · D′（D₀(4) 不截斷），最後截在 1～10 |
| 同一天再作答 | S′ = S · e^(w₁₇(G − 3 + w₁₈)) · S^(−w₁₉)；答對時倍數至少為 1 |

**FSRS-6 預設參數** w₀…w₂₀：

```
0.212, 1.2931, 2.3065, 8.2956, 6.4133, 0.8334, 3.0194, 0.001, 1.8722, 0.1666,
0.796, 1.4835, 0.0614, 0.2629, 1.6483, 0.6014, 1.8729, 0.5425, 0.0912, 0.0658, 0.1542
```

- 這些預設值擬合自 Anki 使用者的閃卡複習紀錄 `[文獻]`，不是台灣高中生的知識點，對 mac model 而言是 `[假設]`。FSRS 附有參數擬合工具，有了延遲後的複習紀錄就應該重新擬合（第 13 節）。
- FSRS 的實作把間隔四捨五入到整天、至少 1 天；本文件的範例與測試數值用未四捨五入的天數，每次複習都套用「答對」或「答錯」式，即使間隔不到一天（例如 R6 的 0.212 天）。「同一天再作答」式只用於實際產品中，同一個日曆日內對同一知識點的第二次以後作答。

### 8.2 範例：R* = 0.9，第一次答對

| 第幾次複習 | 第幾天 | 間隔（天） | 結果 | 複習後 S（天） | 複習後 D |
| --- | --- | --- | --- | --- | --- |
| 第一次學到 | 0 | — | 答對 | 2.307 | 2.118 |
| 1 | 2.31 | 2.31 | 答對 | 11.909 | 2.111 |
| 2 | 14.22 | 11.91 | 答對 | 49.656 | 2.104 |
| 3 | 63.87 | 49.66 | 答對 | 173.821 | 2.097 |
| 3（另一種情況） | 63.87 | 49.66 | 答錯 | 3.019 | 7.390 |
| 4（接答錯之後） | 66.89 | 3.02 | 答對 | 7.903 | 7.378 |

讀法：每次在回想機率剛好 90% 時答對，間隔約乘上 4～5 倍；一次答錯，穩定度掉回約 3 天，難度從 2.1 跳到 7.4，之後間隔成長得慢很多。

### 8.3 為什麼是冪次律

- 實測遺忘曲線較接近冪次律 `[文獻]`。這和「鬆弛」的框架並不衝突：多個鬆弛模式疊加、時間常數有一個分佈，總和就呈現冪次律。FSRS-6 的 R(t) 正好是一個特例：衰減速率呈 Gamma 分佈（形狀參數 w₂₀ = 0.1542）時，指數衰減的平均就是 (1 + F t / S)^(−w₂₀) `[推導]`。

$$
R(t) = \int_0^\infty p(\lambda)\, e^{-\lambda t}\, d\lambda, \quad p(\lambda) = \text{Gamma}(w_{20},\, F/S)
$$

- S 的成長要看複習時機：複習當下的回想機率 R 越低，成功回想後 S 成長越多（間隔效應），上表的 e^(w₁₀(1−R)) 項就是這個效果。
- 用詞：不要用 working memory 指「剛學會、衰減很快」的部分；認知心理學的工作記憶是幾秒到幾十秒、正在腦中運作的資訊，而且 Working Memory 已是 Engine M 系統記憶第一層的名稱（第 9 節）。請稱**快成分**與**慢成分**。

### 8.4 和 m 接起來（提案）

本文件提出一個接法，讓 S_k 決定 m_k 在兩次練習之間如何衰減，也就是 m 的預測步，**此提案尚未實作或驗證**：

$$
P(y = 1 \mid \theta, R_k) = g + (1 - g - s)\, R_k(\Delta t)\, \sigma\big(a(w\cdot\theta - b)\big)
$$

意思是：要答對，必須「會」而且「此刻想得起來」。好處是隔很久之後的答錯，會有一部分歸給遺忘，不會全部算成程度低。代價是 θ 和 S_k 的更新會互相牽動，要用模擬學生先做參數回復測試，才能確定兩者分得開。

## 9. 系統對學習者的記憶

這一節的「記憶」是**產品記得學習者的哪些事**，和第 8 節（學習者還記得多少）是兩件事。數學可以共用，產品意義完全不同。本節是設計規則，**還沒有實作**。

### 9.1 三層

這三層是 NOUS Engine M 中「系統記憶」的架構。名稱必須以下表為準，討論與程式都用這三個名稱：

| 層 | 內容 | 特性 |
| --- | --- | --- |
| Working Memory｜工作記憶 | 當下的對話與任務脈絡 | LLM 直接看得到；容量有限，結束就消失 |
| Episodic Memory｜歷程記憶 | 每次互動的原始紀錄（也就是第 3.2 節的事件） | 需要時用相似度搜尋取回 |
| Profile Memory｜側寫記憶 | 整理過的長期事實，描繪這位學習者 | 由 LLM 從歷程記憶中萃取，寫成結構化欄位 |

**Profile Memory 的完整技術名稱是 Semantic-based Learner Profile Memory**：內容屬於研究文獻所說的語意記憶（semantic memory，脫離特定時間地點的事實），用途是建立學習者側寫。日常討論簡稱 Profile Memory｜側寫記憶。

「由 LLM 協助寫入長期記憶」就是把歷程記憶鞏固成側寫記憶，和研究界主流做法一致：Generative Agents 用「記憶流＋反思」產生高層次記憶，MemGPT 把記憶分層、像作業系統的記憶體分頁 `[文獻]`。

注意不要和第 8 節混淆：第 8 節講的是學習者自己的記憶，那裡的「工作記憶」一詞指認知心理學的概念，和這裡的 Working Memory 是兩回事。

### 9.2 側寫記憶的一筆資料

```json
{
  "mem_id": "mem-0007",
  "learner_id": "u-42",
  "field": "misconception",
  "value": "認為力是維持運動的原因",
  "source": "observed",
  "evidence": ["e-000123", "e-000187"],
  "created_at": "2026-10-20T19:02:00+08:00",

  "status": "active",
  "superseded_by": null

```

### 9.3 規則：穩健的關鍵在規則，不在架構

1. **寫什麼**：必須先定綱要，只能寫入綱要中的欄位，例如學習偏好、常見迷思概念、與陪伴角色的互動史、重要學習事件。不能讓 LLM 自由摘要。
2. **證據來源**：`source` 必須是 `said`（學生說的）、`observed`（系統觀察到的）、`inferred`（LLM 推論的）其中之一。推論的內容不能寫成事實，也不能當成事實對學生說，例如「他是視覺型學習者」。
3. **更新與衝突**：新舊事實矛盾時，以時間戳較新的為準，舊的標成 `superseded`，不讓兩條同時有效。
4. **遺忘**：過時的內容必須能淡出或刪除，例如「正在準備段考」。
5. **隱私**（對未成年學生特別重要）：必須設定哪些資訊絕不寫入，例如身心狀況、家庭狀況；學生必須能看到並刪除系統記住的內容。

### 9.4 共用的數學

和第 8 節同樣用 relaxation dynamics：被多次確認的事實，穩定度變長；很久沒再出現的事實，信心衰減，例如 confidence(t) = confidence₀ · e^(−Δt / stability_days)。成長倍數與門檻 v3.1 都沒有定 `[假設]`。

## 11. 參考虛擬碼

以下是處理一個事件的完整順序。順序重要：先依時間往前推，再用觀察修正，最後才輸出決策。

```python
def on_event(state, ev, items, now):
    if ev.type == "session_start":
        state.affect.p = PI[:]                       # 5.3
        state.affect.p_conf_prev = PI[CONF]
        return state

    dt_sec = seconds(ev.t - state.updated_at)

    # 1. 預測：每個子模型依經過的時間往前推
    state.affect.p = affect_predict(state.affect.p, dt_sec)   # 乘上 expm(Q * dt_min)，>30 分鐘則重設為 PI
    state.calib.post = gaussian_blur(state.calib.post, 0.05 * sqrt(days(dt_sec)))
    maybe_weekly_decay(state.style, now)                      # 計數 × 0.9

    if ev.type == "instruction":
        m_learn_step(state.m, ev.knowledge_point)             # 4.4，連續版未定義
    elif ev.type == "nudge_outcome":
        s = state.style[ev.style]
        if ev.caught: s.ok += 1
        else:         s.fail += 1
    elif ev.type == "response":
        it = items[ev.item_id]
        o = classify_behavior(ev, state)                      # 5.1：正常/卡住/弱項答錯/變慢/快速亂猜
        state.affect.p_conf_prev = state.affect.p[CONF]
        state.affect.p = affect_update(state.affect.p, o)     # 乘上 B[:, o] 再歸一

        if o != RAPID_GUESS:                                  # 4.5
            s_eff = 0.30 if state.affect.p[BORED] >= 0.20 else it.s   # 4.6
            m_update(state.m, it, ev.correct, s_eff)          # 乘上 P 或 1-P，再歸一
            kp_update(state.kp[it.knowledge_point], ev.correct, ev.t) # 8.1：FSRS-6，答對 Good、答錯 Again

        if ev.confidence_q is not None:
            calib_update(state.calib, ev.confidence_q, ev.correct)    # 7.3

    state.updated_at = ev.t
    refresh_summaries(state)       # 平均、SD、區域機率等快取
    return state


def affect_action(p, p_conf_prev):
    conf2 = min(p[CONF], p_conf_prev)
    if p[BORED] >= 0.40: return ("high", "bored")
    if p[FRUS]  >= 0.40: return ("high", "frustrated")
    if conf2    >= 0.40: return ("high", "confused")
    if p[BORED] >= 0.20: return ("low", "bored")
    if p[FRUS]  >= 0.20: return ("low", "frustrated")
    if conf2    >= 0.20: return ("low", "confused")
    if p[CONF]  >= 0.20: return ("wait", "confused")
    return ("none", None)


def m_update(m, it, y, s):
    for cell in m.grid:                          # K ≤ 2 用格點；更多維用粒子
        u = it.a_disc * (dot(it.w, cell.theta) - it.b)
        P = it.g + (1 - it.g - s) * sigmoid(u)
        cell.p *= P if y == 1 else (1 - P)
    normalize(m.grid)


def pick_diagnostic(m, bank, used):
    Sinv = inverse(m.cov)
    best, best_v = None, -inf
    for k, it in enumerate(bank):
        if used[k]: continue
        f = fisher(it, m.mean)                   # 4.7 的 f_k
        v = det(Sinv + f * outer(it.w, it.w))
        if v > best_v: best, best_v = k, v
    return best
```

### 14.3 容易誤解的地方

- **c 不是能力**。程度低但老實說沒把握，c 仍然好。不要把 c 當成第二個程度分數。
- **a_slow 不是學習人格**。它只是「最近哪種推法有效」的計數，每週淡出，隨時會變。
- **所有機率都是模型的估計**，不是實測過的事實。a_fast 說 40% 無聊，意思是「依目前的 T、B 與觀察，模型認為 40%」，在 T、B 校準之前，這個數字的絕對值不可信。
- **模擬結果是最理想的情況**：模擬學習者完全照模型行動。真實學生的表現只會更差。
- **85% 是練習題的起點，不是定律**；診斷題要的是約 50%。
- **SD 是「我們多不確定」，不是學生的穩定度**。SD 大代表資料還不夠，不代表學生表現忽高忽低。
- **「抓到 21%」不是「正確率 21%」**：前者是狀態片段被發現的比例，後者是警報當中對的比例，兩個要分開看（5.5 的定義）。
- **T 的對角線不是半衰期**：一分鐘後仍在某狀態的機率，包括離開又回來的人。半衰期要從 Q 算（5.2）。
- **FSRS 的 S 不是「時間常數」**：S 是回想機率降到 90% 的天數，R* = 0.9 時下次複習就在 S 天後（8.1）。
