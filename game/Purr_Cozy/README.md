# Purr Cozy Web 0.92.14

本版以 0.92.13 為基礎，保留自適應測驗、Meow Typo、SpeechSynthesis 英文發音、音效、雲端存檔、寵物與既有玩法。

## 本次更新

- 家具、配色變體、壁紙、地板、窗景、人物紙娃娃、貓咪動作與旅行商人場景改用 PNG 資源。遊戲程式負責選幀、分層、換色、移動及互動，不再呼叫原本的像素圖形繪製器。
- `assets/png/` 收錄實際資源；`godot/` 提供對應的 `.tres`、動畫與座標資料。素材維持目前 Web 遊戲的原有像素風格。
- 啟動前下載、逐檔 SHA-256 驗證並儲存素材；素材完整可用後才接續讀取雲端存檔及進房間。保留最少三秒的遊戲開場。
- 本機快取以檔案內容辨識。更新時先檢查，僅補下載有改動或遺失的檔案；首次載入會用合併素材包減少網路請求。失敗時保留載入畫面並顯示重試。
- 版本只修改 `version.json`。`resources.json` 與 `resources.bin` 由工具產生，不要手動改其雜湊值。
- 購買主題會立即套用壁紙、地板、一扇既有窗戶及一張既有書桌，並加入一件代表家具。其他家具保留原位置。重複套用不重複增減物品；其餘套組家具放入收納箱。
- 沒有現成窗戶或書桌時不強制新增。代表家具會先找空位；只有完全找不到空位時，才將必要的原家具移回收納箱，不銷毀物品。桌上小物能留則保留，放不下才收納。

## 部署與原檔保留

1. 備份原本的整個資料夾及 Firebase 設定。
2. 將本包遊戲資料夾內容放到原網站位置。使用原本的同一個網域與路徑，瀏覽器快取和登入狀態才沿用同一個來源。
3. **本次收到的專案沒有 music 音樂資料夾。請把你原有的 `music/` 原封不動保留或放回；本包沒有重新提供歌曲與同步歌詞檔。**
4. 若要將放回的本地歌曲也納入啟動前預載，放好 `music/` 後，執行 `Rebuild-Resources.cmd`。需要 Python 3，工具只用標準函式庫。未執行時，歌曲仍走原本的音樂載入方式。
5. 本包沿用已提供的 `js/firebase-config.js`、`firebase.json`、`firestore.rules`，沒有替換後端資料庫或變更權限規則。本地測試未登入你的 Google 帳號，雲端資料未被修改。
6. `apple-touch-icon.png` 已從目前公開網站取回原圖（1024×1024），不是放大的小圖示。
7. 靜態網站須使用 HTTPS。本機可在遊戲資料夾執行 `python -m http.server 8000`，然後打開 `http://localhost:8000/`。請勿用 file:// 雙擊執行。

## 改圖、改程式與發新版

1. 修改對應的 PNG 或程式。
2. 在 `version.json` 增加 `version` 並更新 `date`，不要在其他 JS 寫死版號。
3. 執行 `Rebuild-Resources.cmd` 或 `python tools/rebuild-resources.py`。
4. 一起上傳 PNG／程式、`resources.json`、`resources.bin`、`version.json`；建議最後上傳 `version.json`，讓版本公告在素材可下載後生效。
5. 使用原有分層紙娃娃時，`masks/` 是換色角色索引，不是一般插圖；請參考 `godot/README.md`，不要把索引圖當彩色成品修圖。

## 預載範圍

清單包含本包提供的 PNG、字型、UI、單字資料、程式與本地音效；字型已放在本地，無須向 Google Fonts 臨時取字。若放回 music 後重新產生清單，也會列入 MP3、OGG、FLAC、M4A、LRC、SRT 等本地檔案。

YouTube 串流、Google 登入、Firebase 雲端存檔、GPS 天氣及瀏覽器語音合成服務仍依各自服務運作；它們不是可以打包到網站資料夾的本地素材。瀏覽器若清除網站資料、使用無痕模式或回收儲存空間，下次會重新下載。

首次成功啟動並完成服務工作者安裝後，可以離線讀取已完整快取的遊戲；線上服務仍需要網路。尚未成功下載的新版不會覆蓋上一份完整可用的素材紀錄。

## 圖片與互動

- 邏輯房間尺寸 240×180，素材以原始像素尺寸儲存；放大請用 nearest，避免模糊。
- 椅子獨立擺放使用正面；靠書桌或人物坐在椅上用功時使用背面；坐姿遮擋使用相同背面。
- 貓咪以 PNG 動作幀播放；玩具、梳毛、如廁、訓練等仍由遊戲狀態驅動。移動、翻轉、光照、陰影與粒子效果保留互動運算。
- 分開的床被、椅背與貓砂盆前緣放在 `assets/png/occlusion/` 及家具分層資訊中，方便移植時按角色遮擋順序繪製。
- 開啟 `godot/preview.html`（透過同一個本地伺服器）可搜尋並查看家具 PNG。

檢驗摘要見 `docs/驗證摘要.md`。Godot 資源已做路徑與圖框靜態檢查，尚未在 Godot 編輯器實際執行；本包是可執行 Web 版與移植素材，不是完整 Godot 遊戲專案。
