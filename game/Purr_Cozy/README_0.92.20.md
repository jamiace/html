# Purr Cozy 0.92.20 — 啟動累積修正

本包包含 0.92.18 之後的必要修改，可覆蓋 0.92.18 或 0.92.19。必須合併解壓所有子資料夾，不是只複製根目錄。

## 這次實際找到的問題
線上與本機專案的 version.json 雖顯示 0.92.19，但 asset-cache.js、purr-boot.js 仍是 0.92.18，缺少文字換行正規化與第一錯誤保留。music-playlists.js 也尚不存在。另有字型抽查回傳暫時性 503。
加入啟動入口的 checksum 查詢參數、載入器與清單格式檢查，避免無聲地使用不相容舊載入器；下載 5xx／429／網路失敗最多嘗試三次，每次上限 15 秒，永久 4xx 不重試。第一個錯誤會保留檔名。這些改動不會清除玩家存檔或全部快取。

## 安裝
1. 將 ZIP 全部解壓到原 Purr_Cozy 根目錄，合併 js、data、i18n、tools 等資料夾。
2. 將修改的檔案與 resources.json 一起部署，最後上傳 version.json。
3. 如在自己完整資料夾重新產生清單，先雙擊 Update-Game.cmd，再部署。沒有必要自行改版號。
4. 部署完成後重新整理遊戲。

## 已包含
CRLF/LF 文字正規化、CRC32 局部更新、音檔排除、內建清單 data/music-builtins.json，以及玩家清單分流與雲端存檔序列化。
自建清單同步到帳號存檔，本機匯入音檔依然不會上傳雲端。保留 0.92.18 的高清家具試用，不變動房間擺放。

本包的清單以提供的程式／素材為範圍，不包含原資料夾額外的音樂與歌詞。音樂仍按需串流。若重新執行工具，音檔排除但歌詞與封面仍納入更新。
驗證含線上檔案比對、程式測試與 CRC。未完成真實瀏覽器畫面測試；前次瀏覽器啟動遭自動核准審查拒絕，環境不開放所需沙箱核准。
