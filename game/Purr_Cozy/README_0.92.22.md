# Purr Cozy 0.92.22 — 預設家具高清與縮放穩定
覆蓋 0.92.21，完整合併子資料夾。執行一次 Update-Game.cmd，將修改、build-manifests 新檔、resources.json、version.json 一次 commit/push。

預設房間三件家具直接使用新高清插圖：書桌 desk、床頭櫃 nightstand、虎尾蘭 plant_snake。既有房間只要仍有這三個家具 ID，會直接看到新外觀，不增加家具、不重設房間、不改存檔。若已收納或換成其他款，請放回這些款式。桌面物品及原有家具功能保留。此前角度不同的茶几、抹茶沙發、龜背芋試用替換已停用；本版只啟用這三件正面重畫。網址不要帶 hdFurniture=0，該參數會關閉所有高清試用。

這次已依原始像素圖改回幾乎正面的固定視角，保留水平桌面與正面抽屜，不採用上一批高俯角側面透視。

新圖檔 assets/png/hd/default-furniture-atlas.png；Godot 圖集區域資料見 default-furniture-regions.json。這是三件共用 PNG 圖集，不是把圖縮成舊像素尺寸的 PNG。低解析代理僅供碰撞與擺放，實際顯示用高清來源。保留原家具尺寸與桌面承載資料，試作手繪輪廓與角色接觸仍需實際檢視。

縮放修正：畫布解析度不再讀取每幀 getBoundingClientRect 的變形尺寸，而採 Game.scale、裝置像素密度與放大狀態。內部倍率為穩定的整數，同尺寸不重建畫布。手機／桌機移除原 86% 取整門檻，允許小於 1 倍，避免窄畫面突然跳到另一檔尺寸；手機放大不再使用 steps(4) 跳格轉場。人物與貓咪仍使用像素繪製。

程式測試涵蓋窄畫面、DPR、放大切換與反覆渲染的畫布尺寸穩定性，並驗證高清素材綁定及 checksum。尚未完成真實手機瀏覽器畫面／FPS 實測；前次瀏覽器啟動遭自動核准審查拒絕，環境不開放所需沙箱核准，不能宣稱已消除所有裝置的抖動。
