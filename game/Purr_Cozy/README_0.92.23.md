# Purr Cozy 0.92.23 選擇題快捷鍵修正
覆蓋 0.92.22。執行 Update-Game.cmd 後一次 commit/push。
選擇題改用視窗捕獲階段處理實體 Digit1–4／Numpad1–4，同時支援一般與全形數字。忽略長按、Ctrl/Alt/Meta、IME 組字與輸入欄，只有目前最上層的選擇題可以作答，不影響拼字、預習或 Meow Typo。移除舊重複數字作答分支。保留答題動畫與原有作答、獎勵、語音流程。
原程式只依 e.key 辨識數字，且在文件冒泡階段處理；此修正同時補上實體鍵辨識與事件處理順序。未在使用者當時的瀏覽器重現，不能斷言當時是哪一項因素造成。
