# 小窩時光 v0.92：明暗介面與測驗重試修正

版本維持 0.92；僅更新快取識別，讓瀏覽器抓到修正檔案。

## 安裝
將 css/style.css、js/learn.js、js/life.js、js/challenge.js、sw.js 覆蓋到既有網站的相同路徑。保留自己的 index.html、Firebase 設定、圖示、字型及音樂。部署後重新整理。

## 複習換道具任務
- 困難任務需要兩輪各 5/5 全對，不必連續成功。失敗不扣已完成次數，也沒有重試冷卻。
- 普通任務換到道具就算一次；每輪答對 3～4 題得 1 個道具，全對得 2 個。
- 一般練習及今日單字不計入「複習換道具」任務。
- 任務的「前往」直接開啟道具選擇；結果顯示有沒有計入任務及目前進度。
- 每輪都提供「再試一次／再換一次」，即使已拿到一個道具，仍可再挑戰全對。
- 同一輪只能結算一次，不會因重複呼叫再發道具或增加任務次數。
- 本機未重現「首次失敗後永遠無法成功」；測得原本計分可以 0/2 → 1/2 → 2/2。這次修正的是入口、重試按鈕、規則提示及結算防重複。
- 主人／寵物升級是另一種測驗：8 題答對 6 題通過；失敗後仍維持原本一小時冷卻。

## 明暗介面
升級卡片改用跟隨主題的背景與文字配對；統一修正提示文字、警告／成功色、停用按鈕、故事章節、音樂選取項目、便條與團隊倒數的對比。停用與已完成狀態不再整塊降低透明度，保持文字清楚。

## 驗證範圍
- Chromium 本機桌面 1200×950、手機尺寸 390×844，兩種明暗主題。
- 每種尺寸 204 個視窗、頁籤與條件狀態；文字與背景對比檢查無低於 4.5:1 的發現。
- 29 個視窗的本機可開啟狀態，以及單字複習、作答、對錯提示、主人／寵物升級卡、停用等狀態。
- 連續成績 1、3、4、5、0、5 題正確，困難任務進度為 0、0、0、1、1、2；重新整理後保留 2/2。
- 主人及寵物測驗先失敗、冷卻後成功；12 種 Enter／輸入法情境與左右牆輪廓回歸通過。
- 未連接真實帳號及遠端好友資料測試，亦未在實體 Android Firefox 上執行。本次沒有更動登入或後端規則。
