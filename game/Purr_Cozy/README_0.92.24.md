# Purr Cozy 0.92.24 更新包

2026/10/31。此包以 0.92.23 Pixel 網頁版為基礎，屬於覆蓋更新，不是可刪除原資料夾後重裝的完整包。未部署 GitHub，未修改你的 D 槽原始專案。

## 安裝

1. 備份目前遊戲資料夾與重要存檔。
2. 將 ZIP 裡的檔案、子資料夾覆蓋到 Purr_Cozy 根目錄（index.html 所在位置）。保留原本的 music、vocab、其餘素材與存檔，不要先刪除整個資料夾。
3. 在你自己的完整資料夾執行一次 Update-Game.cmd。它會以本機完整檔案重新建立 CRC32 清單，排除音樂檔案；Rebuild-Resources.cmd 也轉呼叫同一工具。
4. 將所有變更（包含 version.json、resources.json、build-manifests）一起 commit，再 push 一次即可。不必部署後再補傳版本檔。
5. 進遊戲確認版號 0.92.24。這次不載入 HD 家具模組，保留原本 Pixel 顯示。

## 功能與修正

- 姓名及狀態輸入支援儲存按鈕、Enter、離開輸入欄後儲存；清空狀態也是有效修改。修正舊編輯器誤寫切換後存檔、狀態雲端合併、社交發佈節流吞掉最新修改等問題。
- 新放置的筆電、螢幕、電視等設備預設關閉。點擊先打開，開機後才提供相應功能，選取時顯示關機按鈕；關機停止光源。既有存檔中的開機狀態保留。
- 商店重整類別與房間外觀分組；窗戶放在房間外觀，影音設備獨立分類。商品圖片使用房間本身 PNG，發光商品優先展示點亮圖。
- 增加 60 個造型系列 × 5 款，共 300 個商品條目，包含樣式變體，並非 300 種完全不同的家具。電視包含映像管、攜帶式、寬螢幕、雙喇叭、壁掛款。
- 家具包含電玩、VR、手把、裝飾車牌、交通小物、收納、座椅、燈具、植物、金魚缸、水晶球、獎盃及貓用品等；保留原有家具功能，僅適合的物品提供簡單效果或遊戲。
- 共 13 種簡單遊戲規則：四組配對、數字滑塊、轉線板、音符記憶、找不同、依序點星、迷宮、直線停車、反應、釣魚反應、疊疊樂、投擲時機、簡易彈珠。部分是同類時機玩法的不同主題。
- 小遊戲不扣資源。每日每完成 5 局得到 2 次幸運加成，最多計 20 局、持有上限 8 次；幸運機率增加 8 個百分點、上限 40%，幸運觸發才消耗。15 局可恢復一次已用掉的拜訪幫忙，限每日一次。不修改英文適性出題難度。
- 新增五種毛色共 400 張動作 PNG：上跳、下跳、跑動、挖砂、蹲姿、撥物、嚇阻、打架。向上跳使用 16 張真正伸展的姿勢，不以走路圖片拉長代替。
- 搗蛋或高壓貓咪可能在有乾淨貓砂盆時仍亂尿；小物可能被推倒。事件先走近並播放動作，再留下可點擊清理的污漬或翻倒物；清理可回復原擺位。
- 行為僅在自己房間、前景遊玩且適合行動時累積；總髒亂上限 3 處，避免離線後大量補發。亂尿每貓至少 5 分鐘／房間 3 分鐘；推物每貓 10 分鐘／房間 3 分鐘，魚缸額外 3 小時；打架有房間 15 分鐘及同對貓 25 分鐘冷卻。這些是冷卻下限，不保證每到時間就發生；實際仍受性格、壓力、距離與機率影響。
- 普通寵物 UI 不再展示與其他貓咪的關係數字，行為仍保留隱藏關係資料。
- 星軌時鐘去除底圖固定指針，保留動態指針；窗外時間仍依環境時刻，而非室內燈光亮度。

## 驗證範圍

已執行 JavaScript 語法、JSON／PNG 參照、CRC32 資源完整性與 ZIP 完整性檢查；Node 模擬環境通過 1,793 項條件檢查，涵蓋分類、設備開關、存檔指紋、發佈佇列、清空狀態、小遊戲判定、幫忙與獎勵限制、貓咪動作與事件取消。

尚未用實際桌機／手機瀏覽器完整走玩，也未登入你的 Google／Firebase 帳戶測試雲端連線。模擬通過不代表所有既有 UI 已完成實機驗收；請先本機試玩再部署。
