# 模擬高中生（一週）

`sim.cjs` 讓 30 位模擬高中生在真的遊戲裡學習：開遊戲、做每日複習、自由練習、貓咪打字，會分心、會半途離開，也可能好幾天不上線或直接放棄。他們的答題由記憶模型決定，產生的學習紀錄和真實玩家格式相同，裝置代號以 `sim` 開頭，分析頁面可以用「玩家」篩選分開看。

## 參數依據

| 項目 | 數據 | 用在哪裡 |
|---|---|---|
| 英文程度 | 115 學測英文五標：頂標 13、前標 11、均標 8、後標 5、底標 3 級分（[TVBS](https://news.tvbs.com.tw/life/3135746)） | 依這個分布抽每個人的級分；級分決定每個程度單字「本來就會」的機率（均標：L1 約 90%、L3 約 60%、L5 約 18%） |
| 課綱字彙量 | 普高聚焦學測常考 4,500 字，高中每學期新字不超過 600（[遠見](https://www.gvm.com.tw/article/42357)） | 依級分選擇勾選的程度（高分勾 L3–L6，低分勾 L1–L2） |
| 補習 | 超過 6 成學生放學後補習，6 成補到晚上 9 點、23% 到 10 點以後（[兒盟，公視](https://news.pts.org.tw/article/662957)） | 62% 的人「有補習」，平日傍晚幾乎不上線，晚上才玩 |
| 睡眠 | 93% 睡不到 8 小時、37% 只睡 5–6 小時（同上） | 有「睡前固定型」，多半在 22:30 那一段玩 |
| 上網時間 | 國中生每週上網 38.4 小時，91.6% 有自己的手機（[兒盟，聯合報](https://udn.com/news/story/6898/9715840)） | 72% 用手機玩（直式畫面） |
| 學習時段 | Duolingo：睡前 22–24 點最活躍，每天固定練習的人成效最好（[WEF / Duolingo](https://www.weforum.org/stories/education-and-skills/the-best-time-of-day-to-learn-a-new-language-according-duolingo-data/)） | 晚上兩段（19:30、22:30）的上線機率最高 |

| 使用時間與流失 | 教育 App 平均每天 14.7 分鐘；第 30 天留存約 2–4%（[Business of Apps](https://businessofapps.com/?p=98187)） | 每次玩 3–45 分鐘；三分鐘熱度型、試玩就走型很快流失 |

## 六種類型

| 類型 | 特徵 |
|---|---|
| 睡前固定型 | 幾乎每天睡前玩 8–22 分鐘，很少放棄 |
| 補習晚歸型 | 平日傍晚在補習，晚上回家玩 4–12 分鐘，比較容易中斷 |
| 三分鐘熱度型 | 第一天玩很久（15–45 分鐘），之後每天興趣減半 |
| 隨性型 | 想到才玩，時段隨機，每次很短 |
| 週末型 | 平日很少玩，週末玩比較久 |
| 試玩就走型 | 第一天玩幾分鐘，之後幾乎不回來 |

另外每個人還有：作答速度、拼字手滑機率、複習卡是否老實按「不熟」、分心機率（每題 2–8% 會停 15–90 秒），以及偏好的玩法（每日複習、自由練習、貓咪打字）。「本來就會的字」會隨時間遺忘，答對會記更久、答錯會忘更快，看過卡片後有一定機率學會。

## 執行

```
node tools/sim/sim.cjs --slot night     # morning（約 7:00）、noon（12:30）、evening（19:30）、night（22:30）
```

- 狀態（每個人的瀏覽器存檔、記憶模型、上線紀錄）存在專案根目錄的 `.sim/`，已加入 `.gitignore`，不會被 commit。
- 每次執行的結果在 `.sim/logs/日期-時段.json`。
- 第一次執行的日期就是第 1 天，`.sim/config.json` 的 `days` 預設 7 天，第 8 天起不會再有人上線。
- 測試用：`--fast 12`（等待時間縮短 12 倍）、`--tag test-`（裝置代號改成 test- 開頭，分析頁面預設會排除）、`--only sim01,sim02`、`--force`。

## 限制

- 模擬學生都**沒有登入**，所以不會用到雲端存檔、好友、排行榜，`acct` 欄位是空的。
- 他們只玩每日複習、自由練習和貓咪打字，不會觸發房間泡泡、寵物訓練、故事、挑戰。
- 答對與否來自模型，不是真的懂英文。適合拿來測試流程和分析頁面，**不能**拿來下「哪些單字比較難」這類結論。

## 0.92.48：30 位測試帳號（小一～社會人士，兩週）

`testers.json` 是另一組 30 人：小一到退休長輩，英文程度從小一到高三以上，各有自己的上線時段（早上、中午、放學、晚上、夜間、深夜）、頻率、喜歡與討厭的玩法。完整說明與給 Claude 執行的兩週試玩腳本在 `docs/試玩計畫-30位測試帳號.md`。

```
node tools/sim/sim.cjs --testers --login --slot evening
```

- `--testers`：改用 `testers.json`，預設 14 天，狀態存在 `.sim/testers/`。
- `--login`：登入 `.sim/accounts.json` 裡的帳號（後台「玩家帳號 → 批次建立測試帳號」下載的檔案）。沒有這個參數就不登入，和原本一樣只存在瀏覽器。
- 除了每日單字、自由練習、Meow Typo，還會依每個人的喜好：程度小測、養貓（餵食、梳毛、丟玩具）、玩房間裡的小遊戲、放音樂（然後不動）、佈置、開番茄鐘、看排行榜。
- 介面語言照 `lang` 切換（sim24、sim30 日文，sim25 簡體）；平板角色用 820×1180。
- `--direct`：不使用共用快取（在本機測試伺服器上跑時用）。
- 測試帳號的學習紀錄與行為摘要 `dev` 以 `test-` 開頭，分析頁預設排除。
