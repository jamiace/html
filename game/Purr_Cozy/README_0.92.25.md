# Purr Cozy 0.92.25：新增家具全面重畫

本次重畫範圍為 0.92.24 新增的 300 個商品（60 系列，各 5 款），不覆蓋原有其他家具或人物圖像；原有貓咪與新增動作一起重畫，沿用五種毛色。

## 圖像

- 新增商品主圖全部重畫為目前確認的小尺寸像素風格；五款各有造型、裝飾及配色差異。
- 遊戲家具主圖與狀態圖的 PNG 畫布全部不超過 40×36 像素。主圖依類型採不同寬高：椅子 18×26、貓跳台 22×36、立燈 14×36、沙發 40×24、手把 16×10、書本 16×12、地毯 40×16。同步調整登錄尺寸、擺放基準、桌面、座位、寵物停留及光源座標。
- 商品展示直接引用房間圖片。開機／點亮、關機、翻倒、貓砂使用狀態及同源圖示遮罩同步更新，不會切換回上一版粗糙圖案。
- 星軌類新時鐘底圖沒有固定指針，指針由遊戲依當下時間繪製。窗戶保留透明開口，由遊戲顯示窗外景象。
- 沿用商品 ID、價格、解鎖等級與互動種類。桌面放物、座椅與寵物停留基準依新輪廓調整。
- 預覽圖是原生 PNG 的整數倍最近鄰放大，預覽圖本身不是遊戲素材。

## 貓咪動作

原有 14 種動作、29 個基礎影格全部重畫，696 組頸部／頭部配件影格及五種毛色圖集同步更新；保留原版臉部特徵與像素配色，重畫身體、腳步與姿勢。另重畫五種毛色的上跳、下跳、跑步、挖砂、蹲姿、撥物、嚇阻、打架，共 400 張動作 PNG。每張維持 28×36 透明影格與一致足底基準；動作本體保留原版小貓尺度，上跳才伸長身體。打架時兩隻貓隱藏，共用位於中央的一團卡通煙霧，偶爾露出貓掌、尾巴及星星，不表現撕咬抓傷。

## 安裝

這是覆蓋更新包，不是完整刪除重裝包。先備份，再把全部內容覆蓋到原 Purr_Cozy 資料夾（index.html 所在層）。保留原有音樂、單字及其他素材；不要先刪除原資料夾。包內同時包含 0.92.24 的相關功能修改，以支援新商品。

覆蓋後，在自己的完整遊戲資料夾執行一次 Update-Game.cmd，將所有變更連同 version.json、resources.json、build-manifests 一起 commit，再 push 一次即可。音樂檔案排除檢查，不需部署後再次補傳版本檔。未操作你的 D 槽專案或 Git 部署。
