## 聲音調整

按鍵聲改為清脆的復古打字機風格：金屬字桿敲擊、機械喀嗒與較輕的回彈聲。使用四組細微音高變化，連續打字時較自然。

Enter 送出採「叮」一聲加上短促的機械回車／換行聲，帶一點收銀機結帳的感覺。答對、答錯都會響，因為這代表送出動作；已回答的題目不會重複觸發。快速連按時淡出上一段回車聲，避免鈴聲重疊堆高音量。

桌機實體鍵盤、貼上，以及手機畫面鍵盤共用同一套音效。沿用目前的音效開關，關閉後兩種效果都不播放。貓叫、英文 SpeechSynthesis 發音與測驗期間降低音樂的設定維持原版。

兩種新聲音均為本次自行合成，不含其他遊戲的錄音，不需下載額外音效或新增音檔。

## 驗證

已在 Chromium 原生 Web Audio 檢查音效緩衝、波形峰值、首尾淡出、實體鍵盤與手機畫面鍵盤、Enter 答對／答錯、避免重複觸發，以及音效開關，並完成實際離線音訊渲染。未捕捉到頁面 JavaScript 錯誤。手機採視窗與觸控模擬，未宣稱已經過 Firefox／手機實機聽音驗證。
