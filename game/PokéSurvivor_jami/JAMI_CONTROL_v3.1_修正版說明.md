# JAMI CONTROL v3.1 — 角色數值與技能羈絆修正版

這是針對 **v3.0** 的增量更新包，不是完整遊戲。

## 修正項目

1. 「套用角色數值」允許基礎攻擊、基礎速度、吸取半徑與每秒恢復使用小數。原本 `baseAtk` 等欄位被錯誤限制為整數，例如 1.25 會造成整個表單報錯。
2. 全部數值先通過檢查才一次寫入角色，不會再出現「顯示套用失敗，但部分數值已修改」。錯誤訊息會標出問題欄位並將輸入框標紅。
3. 羈絆編輯區加入解說與合併預覽，清楚列出每個欄位的技能。可以拆開指定單一羈絆，不用全部拆開。
4. 合併後自動啟用該欄；更換羈絆組主技能時保留其餘技能，不再意外清掉整組；移除重複技能時不會錯誤覆蓋其他欄。
5. 操作後保留編輯區的捲動位置，減少重複尋找羈絆區域。

## 覆蓋的檔案

請備份原遊戲後，將 ZIP 內這兩個檔案覆蓋到你原本網站或本機遊戲同名位置：

```
html/game/PokéSurvivor_jami/
├── js/core/cheats.js
└── css/style.css
```

請保留之前已修復的 `js/core/input.js`。不需改 Firebase、`db.js`、`player.js` 或遊戲素材。你的網頁 `index.html` 若仍逐一載入 .js 檔，直接覆蓋並重新部署，不需要 Build。若你已改成合併式 `js/app.min.js`，需重新建置。

## 技能羈絆操作範例

1. 進入單人戰鬥，輸入 `jami` 開啟控制台，點 **技能配置**。
2. 讓欄位 1 裝上「火花」、欄位 2 裝上「泡沫」，分別按對應的「套用」。
3. 滾到「羈絆合成」，選 **① 主欄位 = 欄位 1（火花）**、**② 要併進去的欄位 = 欄位 2（泡沫）**。
4. 在合併預覽確認「火花＋泡沫」後，按 **「將②合併進①」**。
5. 欄位 1 變成包含兩招的羈絆組；欄位 2 因為被合併而騰出位置（後面的欄位會往前排列）。
6. 合併成功後會自動切換到該羈絆；也可在上方欄位按 **「啟用」**。關閉控制台即可觀察兩招一起發動。
7. 想拆開，就到「羈絆合成」選有兩招的欄位，按 **「拆開①所選的羈絆」**。如果拆開後會超過四欄，請先在概覽啟用實驗模式（上限八欄）。

注意：普通模式每個羈絆最多四招；實驗模式最多八招。這是此控制台的實驗操作，不需要消耗一般遊戲內的羈絆次數。

## 驗證

通過 JavaScript 語法檢查及 Chromium 模擬操作：小數數值套用、錯誤欄位精確提示／原值不被部分覆蓋、羈絆合成與指定拆解、在羈絆中替換技能、保留輸入／鍵盤快捷鍵。
