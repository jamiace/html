PokéSurvivor JAMI 隱藏作弊選單

【如果你已經安裝上一版 Firebase Jami 修改包】
只要把這份修改包內的 js/core/cheats.js 覆蓋到遊戲資料夾相同位置。
如果你要在 GitHub Pages 更新，把 js/core/cheats.js 上傳覆蓋到自己的 GitHub 儲存庫，等待 Pages 部署完成後按 Ctrl+F5 重新整理。

【開啟方式】
1. 本地版用你的本地帳號登入，進入主選單（有開始遊戲、寶可夢收藏等按鈕的標題畫面）。
2. 直接按鍵盤 J A M I，大小寫都可以，每個字母之間不要停超過 2.5 秒。
3. 或者在單人戰鬥時按 Esc 開啟暫停畫面，再依序輸入 J A M I。
4. 按 Esc、× 或「關閉面板」收起 Cheat Mode。
5. F9 快捷鍵已取消。正在戰鬥、抽卡、輸入帳號密碼、其他選單均不啟動。

【重要】
之前為避免作弊資料同步到朋友共用的 Firebase，本版 Cheat Mode 保持「本機 LOCAL 帳號限定」。
GitHub Pages 若啟用了 Firebase 雲端帳號，輸入 JAMI 只會提示停用，不會變更雲端資料。
這次只更換啟動方法，不更改雲端作弊限制。
JAMI 是隱藏鍵盤序列，不是存取權限或密碼保護。
