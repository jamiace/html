# JAMI CONTROL v3.0 · PokéSurvivor 繁體中文版

## 安裝（請先備份完整遊戲與瀏覽器存檔）

這份檔案是**增量更新包**，不是獨立遊戲，**不包含 assets**。請將 ZIP 內四個檔案覆蓋至原遊戲的相同路徑：

```
html/game/PokéSurvivor_jami/
├── css/style.css              ← 新版 JAMI CONTROL 視覺介面
├── js/core/cheats.js          ← 作弊面板全部功能
├── js/entities/player.js      ← 實驗模式多件裝備判定
└── js/systems/spawner.js      ← 指定本局 Boss 召喚
```

不需覆蓋 `index.html`、`dev.html`、`js/core/input.js`、`js/core/db.js` 或 Firebase 設定。請**保留之前已修好的鍵盤 `input.js`**，以及你已設定的「新玩家 0 金幣」。

目前的 Jami 網頁版 `index.html` 使用逐一載入的 JavaScript，不需執行 Node.js Build。上傳後等 GitHub Pages 部署完成，使用 `Ctrl + Shift + R` 強制重新載入。如果未出現新版介面，請至瀏覽器開發者工具 Network 確認載入的 `js/core/cheats.js` 與 `css/style.css` 是否已更新。若你另外修改成載入 `js/app.min.js`，就必須改用相應的 build 流程。

## 開啟與關閉

- **任何畫面**依序輸入 `JAMI`，不分大小寫，每個字母的間隔小於 2.5 秒。不再限制標題或暫停畫面，也不使用 F9。
- **Esc**、右上角 ×、面板底部關閉鈕，都可關閉面板。
- 在登入帳密、暱稱或任何可編輯輸入欄位內輸入 JAMI，**不會誤開啟**。
- 面板打開時，單人遊戲的世界模擬暫停；關閉後繼續。對多人合作模式不開放更改世界或角色數值，以免影響其他玩家。

## 功能分類

**概覽**：快速回滿生命、加級、無敵、清怪、下載存檔；實驗模式切換。

**寶可夢**：從圖鑑選角；即時換角色及異色外觀；設定下次開局夥伴；生命／最大生命／等級／攻擊／移速／暴擊／回復／磁力範圍。

**技能配置**：四個技能欄位（實驗模式八欄）、不限屬性任意替換，設定技能等級、指定目前作用技能、解除技能、全技能滿等或進化、羈絆組合／拆解；個別技能傷害、冷卻、攻擊數量、攻擊範圍、彈速、穿透及持續時間。

**裝備實驗室**：即時更換與卸下十一種原版裝備；實驗模式允許加入多件不同的裝備，對應能力真正生效，移除時撤銷該件的效果。裝備發現紀錄可解鎖。

**戰鬥數值**：無敵、傷害倍率、移動倍率、技能冷卻倍率、經驗倍率；立即升級、吸收掉落物、清除畫面敵人等。

**世界控制**：切換生態區、強制天氣、指定遊戲時間與速度、產生普通／異色敵人、指定本局五個 Boss 之一、觸發三種事件、召喚寶藏敵人、開啟裂縫、指定／進入屬性競技場。

**資源與收藏**：金幣、一般／十連券，單隻或全圖鑑解鎖、異色解鎖、單隻或目前夥伴永久升級、各區保底次數、強制下一抽達成傳說保底，以及指定後續數次異色抽卡測試。

**預設與備份**：把目前角色、技能、羈絆、裝備、額外裝備、數值與倍率存成本地配置，能再次套用、刪除、匯出 JSON；另可下載目前的完整帳號存檔作備份。

## 存檔區分

- 「當局」的屬性、招式、裝備、敵人及世界參數，只影響該局；重新開局不會自動繼承。
- 金幣、抽卡券、收藏、保底、永久升級及下次開局的夥伴，會使用遊戲原來的 `G.DB.commit(true)`。Firebase 帳號會先寫在本機快取，再嘗試同步；若未同步完成，請不要立即換裝置。
- 套用的測試預設儲存在**該瀏覽器的 localStorage**，不會自動跨裝置同步。可以匯出 JSON 供人工保存。
- 變更帳號資料前會在瀏覽器建立備份。極端數值可能使遊戲難以操作或變慢，請先下載存檔。
- JAMI 是所有玩家都能輸入的隱藏指令，**不是只有站長可用的權限系統**。所有已登入的玩家都可修改自己的 Firebase 存檔；不能讀取其他人的存檔。多人連線不允許改戰鬥狀態。

## 注意事項與測試範圍

此次已對新程式進行 JavaScript 語法檢查、瀏覽器面板渲染與點擊互動測試、JAMI／Esc 鍵盤測試、模擬角色切換、技能替換、裝備疊加／卸除、資源設定、保底、配置保存與載入測試。測試也涵蓋窄螢幕介面。但由於此前提供的原始碼壓縮包不含 `assets` 實際素材，也未接入你的真實 Firebase 專案進行端對端測試，因此**完整遊戲場景、Firebase 寫入、極端技能組合、裂縫及多人相容性仍需你在網站實際測試**。
