# Pocket Nook 0.911 修正說明

本次依指定使用 0.911，未另外遞增版號。原有存檔鍵值、資料結構版本與雲端設定維持相容。

## 音樂

- 專輯區不再被視窗的彈性排版壓到只剩部分封面。預設按專輯卡片實際高度呈現，最高 486px；超過範圍可捲動。
- 專輯區、歌曲清單下方各新增高度把手，可上下拖曳，兩者獨立調整。高度會記住，介面更新、關閉視窗或重開遊戲都會保留。
- 雙擊把手恢復該區預設高度；鍵盤聚焦後可用上下方向鍵調整，Home 恢復預設。手機也保留把手。
- 整個音樂視窗仍可從右下角調整大小；內部區域總高度超過視窗時，視窗內容可以捲動。
- 取消舊程式更新時強制改播 YouTube 的行為，記住上次選擇的內建、本機或 YouTube 曲目與播放位置。音樂庫排序改變時優先依曲目識別資料恢復。
- 上次的音樂庫暫時讀取不到時，保留原來源並顯示提示，不自動改播 YouTube。
- 沒有封面的音樂檔會正常完成讀取；網路失敗有 60 秒重試間隔，避免反覆下載封面、持續重建音樂介面。
- 房間更新迴圈已隔離介面、人物、生活系統及繪圖錯誤，單一錯誤不會中斷後續動畫更新。

## 禮物與互動訊息

- 禮物盒、折價券、保底資訊與重複物品說明改為靠左、完整換行。物品預覽仍置於中央。
- 連續操作家具時立即移除上一則家具訊息；不同人物、寵物仍各自保留其訊息。
- 電腦等長訊息會自動換行，不再以省略號截斷，靠近房間邊緣時也會調整位置。
- 對話泡泡改為鵝黃色邊框，邊框深於泡泡底色；泡泡與尾巴有圓角，不再使用黑色像素外框。

## 貓跳台

- 點擊貓跳台會呼喚有空的貓咪，走到下方後依序跳到中層、頂層，最後睡覺或坐著休息。
- 自主選擇貓跳台休息時使用相同分段路線；離開時也逐層跳回地面。
- 路線會隨家具翻轉，並保留其他貓咪占用位置的檢查。

## 旅行商人故事

- 點選已完成的章節數字即可回顧，支援上一章、下一章與返回本週故事。
- 回顧直接顯示故事，不進入測驗，也不改變獎勵、進度、命名、學習紀錄或收藏。
- 重複完成同章的呼叫不會再次發放金幣、經驗或紀念品。

## 驗證

使用 Chromium 實際執行專輯與清單高度調整、重新整理後的高度保留、長訊息、禮物盒排版、內建及本機音樂接續播放、舊存檔來源保留、故事回顧、貓咪分段上下跳台與手機版介面檢查。另注入音樂介面錯誤，確認房間與人物仍持續更新，並驗證封面失敗不會形成無限重試。

YouTube 以模擬播放器驗證原影片與播放位置的恢復流程；外部 YouTube、Google Drive 與 Firebase 正式服務未在此環境進行實際連線驗收。

## 替換

解壓縮後，以 pocket-nook 資料夾中的檔案覆蓋原專案，再依原本方式啟動或部署。遊戲不需要安裝 npm 套件。已開啟的遊戲頁面請重新整理，讓瀏覽器載入本次修正的程式與樣式。
