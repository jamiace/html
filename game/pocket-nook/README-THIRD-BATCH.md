# Pocket Nook 0.92 — 第三批 HD-2D

請先安裝第一、第二批，再將本包的 `js`、`assets` 資料夾合併覆蓋到遊戲根目錄並重新整理。版本維持 0.92，不需要修改 index.html。

本批對應 204 款商品、120 個基本造型，其中 4 個已完成造型沿用前批。使用內建繪圖工具逐款新繪 116 個造型、72 張亮燈圖與寵物碗的 3 種飼料量，共 191 張新 PNG；與前兩批合計 373 張 HD 圖。

新增燈具、霓虹、窗框、時鐘、鏡子、電器與寵物用品。開關圖保留同一套外框與支架，光暈及照向周圍物件的效果仍由引擎繪製。窗框開口對齊既有窗景座標；左右牆使用同樣的 HD 素材投影，動態窗景與天氣仍保留。

程式調整集中在 `js/hd2d.js`：
- 依飼料剩餘量選用寵物碗 HD 圖，保持空碗、低量、半滿與滿碗四種顯示。
- 所有窗框統一沿用既有的窗景與窗簾／障子繪製流程，包含拱形窗。
- 已有獨立熄燈圖的燈籠不再重複套用舊版強制壓暗濾鏡。

本包只新增第三批 191 張圖片；合併圖包清單保留前批素材。原像素圖片、存檔 ID、場景 2 倍畫布、短影子與既有光照設定均維持。

開啟 `preview.html` 查看全部新圖。`ART-PROMPTS.json` 為逐款繪圖提示詞；`HD2D-BATCHES.json` 保存五批進度，後續從第四批接續。
