# 小窩時光 Pocket Nook

## 玩家指南與生活攻略

**每天學一點，讓喜歡的小房間慢慢長大。**

《小窩時光》把英文單字、番茄鐘與寵物生活放在同一個房間裡。你可以專心讀書或工作，休息時餵餵毛孩、整理盆栽，再用累積的金幣添購家具、換造型，邀朋友來互相照顧小窩。

這裡沒有必須趕完的主線。你可以把「今天學會幾個字」「養大一隻寵物」「存到喜歡的房間主題」當作自己的目標，按照適合的步調遊玩。

## 新手起步

### 你的第一個小窩

新遊戲會提供基本房間、**150 金幣**，以及一隻名叫「麻糬」的橘貓。收納箱裡也有幾件可用來佈置的小物，道具則備有少量食物與用品。先四處點點看，不必急著把起始金幣花完。

房間與角色的成長主要靠三件事連在一起：**學習取得資源、用資源照顧生活、再把生活獎勵投入自己喜歡的收藏。** 番茄鐘則讓你在真正讀書或工作的時候，也能持續累積金幣與經驗。

### 第一次開啟時，可以照這個順序玩

1. **設定名字。** 點右上角帳號按鈕，替自己的名片取個名字；需要社交或跨裝置接續時，再完成登入。
2. **認識麻糬。** 打開「寵物」，看看飽足、心情、清潔與精力。可以摸摸牠，或試著餵一份食物。
3. **開始今日單字。** 到「學習」完成 20 個字的複習，再做 10 題小測驗。
4. **去任務領獎。** 完成學習後，還要到「任務 → 每日任務」按下領取，才會拿到該張任務卡的獎勵。
5. **替接下來的半小時安排一件事。** 在待辦清單寫下要做的內容，開番茄鐘開始專注。
6. **休息時整理房間。** 點需求泡泡、補食物、梳毛，或從收納箱拿一件家具出來擺放。

> **第一天不用養很多隻寵物。** 先熟悉一隻毛孩的照顧方式，等食物、玩具與空間準備好，再擴大家庭，會比較從容。

### 遊戲的一天與一週

| 項目 | 更新時間 |

| 每日團隊任務 | 當日 06:00 至隔日 06:00 |
| 每週團隊任務 | 週一 06:00 至下週一 06:00 |

### 下方功能列

「番茄鐘」「學習」「任務」「待辦」「便條」「音樂」「商店」「收納」「佈置」「造型」「寵物」「好友」是主要入口。開啟功能視窗不會離開自己的房間；電腦較寬的畫面可同時放幾個視窗，拖動標題列調整位置。

一般狀態下，點家具會觸發互動；進入**佈置模式**後，點家具則是選取與移動。想摸寵物或開關家具，記得先離開佈置模式。

### 房間裡可以點什麼

- **需求泡泡**：打開該項需求與可使用的道具。
- **寵物**：一般情況下摸摸牠；有需要使用用品的需求時，可能先打開需求說明。
- **床與沙發等座位**：休息時讓角色去睡覺或坐下；專注中會優先維持工作狀態。
- **書桌或工作椅**：打開番茄鐘。
- **燈、窗戶**：開關燈，或拉開、關上窗簾。
- **寵物碗**：開啟照顧頁，選擇碗的使用對象與補充食物。
- **房間裡的禮物盒**：打開升級禮物。
- **角落告示牌**：前往當週旅行商人的攤位。
- **留言本或好友幫忙留下的愛心**：查看幫忙紀錄。

人物與寵物會自己散步、休息和尋找停留處。偶爾經過家具後面是正常的空間表現，不需要把牠們當成待操控的角色一直移動。

## 英文學習

### 收錄內容與程度選擇

遊戲收錄 **6,864 個單字**，分為 Level 1–6。單字卡提供英文、詞性、中文意思與 KK 音標，並可播放發音。

| 程度 | 字數 |
| --- | ---: |
| Level 1 | 1,131 |
| Level 2 | 1,124 |
| Level 3 | 1,103 |
| Level 4 | 1,103 |
| Level 5 | 1,190 |
| Level 6 | 1,213 |
| **合計** | **6,864** |

在「學習」勾選你想加入的程度，至少保留一級。這個選擇主要控制**新字來源**；已經學過、需要複習的單字仍可能再出現。因此取消某一級，不代表過去學過的該級單字會被刪除。

### 今日單字：20 個複習，加 10 題測驗

每日學習分成三步：

| 階段 | 玩法 | 完成後 |
| --- | --- | --- |
| 複習 20 個字 | 點卡片看中文，聽發音，選「記得」或「還不熟」。 | 接著進入小測驗。 |
| 小測驗 10 題 | 從本次複習內容出題，混合不同題型。 | 顯示答對數、所得獎勵與需要再記的字。 |
| 領每日任務獎勵 | 到「任務 → 每日任務」找已完成的今日單字任務卡。 | 取得任務金幣、經驗與隨機道具。 |

選「還不熟」的單字，會優先納入接下來的小測驗。複習時可以用「上一個」回頭看；**進入測驗後不能返回上一題改答案**。

答對時會自動接下一題；答錯時會顯示正確內容，讓你再記一下。每日流程不要求全對才能完成，但答對越多、學習進展越好，能拿到的測驗回饋也越多。

完成今日單字後，可以按「再練一次今天的字」。這會成為額外練習，不會再次發出同一天的每日任務獎勵。

### 四種題型

| 題型 | 你要做的事 | 小提醒 |
| --- | --- | --- |
| 看英文選中文 | 從四個選項選出意思。 | 注意詞性與相近字義。 |
| 看中文選英文 | 從四個英文選項找出對應單字。 | 不只看第一個字母。 |
| 拼字 | 依中文提示輸入英文。 | 會提示首字母與長度；不區分英文大小寫。 |
| 聽發音選中文 | 聽完後選出意思。 | 可以按「再聽一次」。發音功能可用時才會出這種題。 |

### 複習與熟練度

遊戲會安排舊字再次出現。答對後，後續複習間隔會隨熟練度拉長，可能隔 **1、2、4、7、15 天**再出現；答錯的字則會較快回到複習清單，隔天再練。

「看過」「學會」「熟悉」「精熟」代表不同的學習進度，並不是看完一次卡片就全部達成。在單字本中，可以用五格熟練度標記追蹤每個字；答錯後進度可能回退，需要再鞏固。

### 自由練習與單字本

自由練習每次先複習 **10 個字**，接著做 **8 題測驗**；可選擇直接測驗。一般答題金幣每天有 **40 金幣**的練習額度，畫面會顯示剩餘額度；用完後仍可練習，繼續累積學習進度與經驗。這不是所有學習模式共用的總收入上限。

單字本可以搜尋英文或中文，並依 Level 與「全部／還沒學／學習中／熟悉」篩選。每一列可查看詞性、意思與熟練度，也能單獨播放發音。清單很長時會先顯示部分結果，用搜尋更容易找到特定的字。

## 學習換道具

想餵寵物、修燈泡或救盆栽，不一定要先存錢。到「學習」選擇需要的用品，完成一組 **5 個單字、5 題測驗**就能換取。

| 測驗結果 | 可獲得的指定道具 |
| --- | ---: |
| 答對 0–2 題 | 0 個，可再試一次 |
| 答對 3–4 題 | 1 個 |
| 5 題全對 | 2 個 |

這個模式是**先選道具，再完成學習**，不是隨機發一樣你不需要的物品。若從需求卡進入，拿到道具後可能會出現「馬上使用」，可直接回頭處理該項需求。

> **缺錢時的實用做法**：日常消耗品優先用單字換，金幣留給想長期使用的家具、玩具、梳子或房間主題。需要什麼就換什麼，不必等寵物出現泡泡才準備。

## 番茄鐘與專注

### 時間設定與循環

| 模式 | 初始長度 | 可調範圍 |
| --- | ---: | ---: |
| 專注 | 25 分鐘 | 10–60 分鐘，每次增減 5 分鐘 |
| 短休息 | 5 分鐘 | 1–15 分鐘 |
| 長休息 | 15 分鐘 | 5–30 分鐘 |

按「開始」就會倒數；有事可暫停，稍後繼續。「重設」會重開目前這一段；「跳過」則切換到下一個階段，**不會拿到完整完成一輪的額外獎勵**。

每完成四輪專注，接下一次長休息，其餘完成輪次接短休息。可以開啟「專注結束自動開始休息」；休息結束後，仍要自己開始下一輪專注。

### 專注獎勵

專注的基礎回饋是每完整分鐘 **2 金幣、4 經驗**，完整完成一輪另有獎勵。休息時間不會照專注分鐘發獎。

以沒有額外加成的 25 分鐘完整專注為例：

| 來源 | 金幣 | 經驗 |
| --- | ---: | ---: |
| 25 分鐘專注累積 | 50 | 100 |
| 完整完成一輪 | 10 | 15 |
| **合計** | **60** | **115** |

房間舒適度可能提高實拿金幣。飯糰、咖啡分別替下一輪完整完成的專注，追加相當於該輪基礎分鐘收入 **30%** 的金幣、經驗；以 25 分鐘為例，基礎加碼分別是 15 金幣、30 經驗，於完成一輪時結算。若打算更改長度，先暫停或結束目前這段，再設定下一輪，較容易掌握自己的讀書安排。

### 專注時房間會怎麼運作

角色會優先去書桌或工作椅附近。你仍可打開學習、音樂或其他視窗，倒數不會因關掉番茄鐘視窗而停止。分頁切到背景時，遊戲也會檢查正在進行的計時。

**自動開始休息不等於自動無限專注。** 完成一輪、休息結束後，回來確認並重新開始，才是下一段專注。把小窩當成讀書工具時，可以先從待辦清單選好這一輪的目標，結束後再打勾。

## 金幣經驗與舒適度

### 三種成長不要混在一起

| 成長項目 | 用途 | 主要來源 |
| --- | --- | --- |
| 玩家金幣 | 買家具、道具、主題、造型、寵物及用品。 | 專注、學習、任務、照顧、成就與其他生活回饋。 |
| 玩家等級／經驗 | 解鎖可購買商品；升級會掉落禮物盒。 | 專注、測驗、任務、需求、待辦等。 |
| 寵物成長／羈絆 | 長大、開放把戲、培養陪伴關係。 | 照顧、餵食、玩耍、訓練、互動與滿足需求。 |

**升到解鎖等級，代表可以購買，不代表自動擁有。** 家具仍需付金幣，買到後通常先放進收納箱。

### 舒適度怎麼影響收入

擺在房間裡的家具與裝飾會累積舒適度；收在箱裡的物品不算作已擺設。部分主題收藏也會幫助房間的整體舒適程度。

舒適度等級每升一級，適用的金幣收入提高 **3%**，最高 **+30%**。任務視窗會顯示目前等級與加成。這類加成適用於專注、一般測驗、任務、需求等收入；團隊等固定額度獎勵不會因此讓隊員領到不同金額。

遊戲另有少量開啟畫面時的生活收入，適合視為附帶回饋；想穩定添購家具，主力仍是專注、單字與任務。

### 常見收入來源

| 來源 | 遊玩要點 |
| --- | --- |
| 專注 | 按分鐘累積，完整完成另有加碼。 |
| 單字小測驗 | 答對、學習進展與每日學習都會帶來回饋。 |
| 每日任務 | 完成後逐張領取，全部領完再拿全勤加碼。 |
| 房間需求 | 按需求使用用品或完成指定動作。 |
| 成就 | 長期累積目標，每階段達成後另行領取。 |
| 待辦 | 每日有限次數的完成獎勵。 |
| 寵物成長與羈絆 | 升級時得到額外回饋。 |
| 寵物的小禮物 | 多陪伴、觀察毛孩帶來的驚喜。 |
| 好友幫忙 | 成功幫忙有固定回饋，累積後可得抽獎券。 |
| 團隊任務 | 當期隊伍達標後，完成名單全員可領。 |
| 旅行商人收購 | 把符合當週需求的收納物品賣給商人。 |

## 房間需求

需求泡泡是房間裡的人、毛孩與家具在提醒你「現在想要什麼」。點泡泡看說明，也可以從「任務 → 需求」集中查看。

同樣是餵食或清潔，**有沒有完成需求**與**有沒有做過一次動作**是兩回事。寵物的狀態如果還不夠好，做一次照顧不一定就讓泡泡消失；繼續看看狀態條與需求卡。

### 寵物需求

| 需求 | 處理方式 |
| --- | --- |
| 肚子餓 | 餵罐頭、小魚乾或豪華餐；也可預先補碗讓牠自己吃。 |
| 好無聊 | 貓薄荷，或用已擁有的玩具陪牠玩。 |
| 在撒嬌 | 按需求餵零食。 |
| 想被摸摸 | 回房間點牠三下，依泡泡上的進度完成。 |
| 身上髒髒的 | 洗澡，或用梳子逐步提高清潔。 |
| 不太舒服 | 先餵寵物藥，再維持飲食與清潔。 |
| 想學新把戲 | 到把戲分頁完成一次成功訓練。 |
| 想要某件家具 | 把需求指定的家具**擺進房間**；只買好收在箱裡還不算。 |

### 家具與人物需求

| 需求 | 道具／行動 | 處理重點 |
| --- | --- | --- |
| 植物葉子枯黃 | 植物營養液 | 在需求卡對那盆植物使用。 |
| 家具積灰塵 | 清潔噴霧 | 日常點擊家具不等於清潔需求已完成。 |
| 燈泡燒壞 | 燈泡 | 壞掉的燈要修好，才可正常開啟。 |
| 天氣很好 | 打開指定窗戶的窗簾 | 點一下窗戶，讓房間進光。 |
| 角色肚子餓 | 飯糰 | 同時準備下一輪專注的金幣加成。 |
| 角色想睡 | 咖啡 | 同時準備下一輪專注的經驗加成。 |
| 想佈置房間 | 從收納箱擺出一件物品 | 依需求做一次新的擺放。 |
| 房間好暗 | 開啟一盞可正常使用的燈 | 壞掉的燈先換燈泡。 |

完成需求可得到需求卡所列的金幣、經驗；寵物需求還能幫助牠的成長與羈絆。若沒有道具，可直接轉去學習換取，或用金幣在商店購買。

> **不要把一般互動與修復混為一談。** 點健康盆栽澆水、點魚缸餵魚，是生活小互動；已經枯黃的植物或壞掉的燈，仍要依需求使用指定用品。

## 寵物生活

### 可以養幾隻

- 總共最多飼養 **10 隻**，同一種類可以領養多隻。
- 房間裡同時最多 **5 隻**，至少保留 **1 隻**。
- 其他寵物可以住寵物旅館，再依喜好換回房間。
- 寵物旅館中的毛孩不會出現房間需求，狀態會獲得照料，適合暫時減輕照顧負擔。

領養時若房間已滿，新毛孩會先住旅館。到「寵物 → 紀錄」可以選擇「帶回房間」或「送去寵物旅館」。

| 類型 | 外觀 | 開放等級 |
| --- | --- | ---: |
| 貓咪 | 橘貓 | Lv 1；新遊戲已有麻糬 |
| 貓咪 | 灰貓 | Lv 2 |
| 貓咪 | 白貓 | Lv 3 |
| 貓咪 | 黑貓 | Lv 4 |
| 貓咪 | 可可貓 | Lv 5 |
| 柴犬 | 柴犬 | Lv 3 |

領養費會隨已飼養的總數提高，以當下領養畫面顯示為準。每一隻都有自己的名字、個性、成長、羈絆與喜好；相同外觀也不等於相同的毛孩。

### 四條狀態

| 狀態 | 怎麼照顧 | 狀態不足時 |
| --- | --- | --- |
| 飽足 | 直接餵食，或在飼料碗放食物。 | 會想吃東西，太久沒照顧可能不舒服。 |
| 心情 | 陪玩、摸摸、給零食，照顧好其他需要。 | 可能無聊，或不適合繼續訓練。 |
| 清潔 | 梳毛或洗澡。 | 出現清潔需求；長時間太髒可能不舒服。 |
| 精力 | 休息、睡覺。 | 玩耍與訓練會受限制。 |

睡覺恢復精力較快，可以在照顧頁按「去睡覺」。寵物會找床位、坐墊或適合的地板；同一個休息家具不會被多隻寵物同時占用。

關閉遊戲一段時間後，狀態變化較溫和，並不會因這段離開時間直接新增生病。不過離開前補好食物、保持清潔，回來會更舒服。

### 個性與喜好

| 個性 | 可觀察的傾向 |
| --- | --- |
| 貪吃 | 比較容易餓，吃到東西也更開心。 |
| 黏人 | 特別重視陪伴與摸摸。 |
| 活潑 | 喜歡玩耍，也比較不容易累。 |
| 愛睡 | 常常休息，睡眠恢復精力較快。 |
| 愛乾淨 | 比較不容易弄髒，也喜歡梳毛。 |
| 好奇 | 喜歡探索，較容易帶來小驚喜。 |

「愛吃」「愛玩」一開始會顯示問號。試試不同食物和玩具，遇到喜歡的就會揭曉；喜好會讓相應互動更開心，不必先知道答案才能正常照顧。

除了畫面上的個性，毛孩也有各自的小習慣。有的愛看窗外，有的常找舒服的角落；多隻一起住時，也會出現靠近、一起休息或暫時保持距離的互動。這些生活表現適合慢慢觀察，不是另一組必須刷滿的任務。

### 成長與羈絆

寵物成長最高 **Lv 20**，Lv 1–4 是幼貓／幼犬，Lv 5–9 是少年，Lv 10 起成年。餵食、玩耍、清潔、訓練與滿足需求，都能讓牠逐步成長；升級時會得到金幣等回饋，也會開放更多把戲。

羈絆是另一條獨立進度，不等於成長等級。摸摸、餵食、陪玩與照顧能增進感情；羈絆升級會帶來金幣、經驗與零食，熟悉你的寵物也可能帶回小禮物。

### 直接餵與放進碗裡，有什麼不同

| 方式 | 適合情境 | 你需要做的事 |
| --- | --- | --- |
| 直接餵 | 現在要補狀態、完成照顧或回應需求。 | 在寵物照顧頁選擇毛孩，再點食物。 |
| 放進碗裡 | 替接下來的時間準備食物。 | 選碗、補食物，等毛孩餓了自己吃。 |

每個碗最多放 **3 份**食物，可放罐頭、小魚乾或豪華餐。吃的時候會分次取用，畫面會表現空碗、少量、半滿或滿碗的差異；放食物不是立即完成一次直接餵食。

碗可以指定給一隻寵物，也可以改為共用。**有自己專用碗的寵物會使用自己的碗**；若專用碗空了，記得補充或改成共用，不要以為旁邊另一個共用碗有食物就一定會吃到。房間可以擺多個碗，方便分開照顧。

將碗收起時，尚未開始食用的完整份數會回到道具袋；已吃掉一部分的食物不會變回完整道具。離開遊戲前，先檢查碗是誰的、裡面還有多少，會比多買幾個空碗實用。

### 更名、旅館與送養

寵物的名字可在照顧頁編輯，最多 12 個字元。想暫時換一批毛孩陪伴，用旅館就好；「送養」則是讓牠離開目前的家庭，確認後不能復原，也不是暫住旅館。最後一隻寵物不能送養。

## 訓練與把戲

### 訓練條件

到「寵物 → 把戲」選要教的動作。每次訓練是 **4 題單字小測驗，答對至少 3 題才算成功**；一次成功推進一格學習進度，達到所需次數才學會。

開始訓練前，寵物必須達到該把戲的成長等級，沒有生病，精力至少 **25**、心情至少 **35**。每次完成訓練會消耗 **25 精力**，答題沒過也會累，適合穿插休息。

| 把戲 | 寵物等級 | 需要成功訓練 |
| --- | ---: | ---: |
| 坐下 | Lv 1 | 3 次 |
| 握手 | Lv 3 | 4 次 |
| 轉圈圈 | Lv 5 | 5 次 |
| 後空翻 | Lv 7 | 5 次 |
| 中槍 | Lv 9 | 6 次 |
| 喬登三段跳 | Lv 11 | 6 次 |
| 跳火圈 | Lv 13 | 7 次 |
| 麥可舞步45度傾斜 | Lv 15 | 8 次 |

**玩家等級解鎖領養或商品，寵物等級解鎖把戲。** 如果你已經是高等玩家，剛領養的幼寵仍要先成長，不能直接學完所有動作。

### 學會後，讓牠表演給你看

學會的把戲會出現「表演」按鈕；毛孩需要在房間裡，住旅館時要先帶回來。一次只進行一場表演，等前一場結束再選下一個。

| 把戲 | 房間裡可以看到的演出 |
| --- | --- |
| 坐下 | 乖乖坐好，開心地小跳一下。 |
| 握手 | 主人走過來伸手，毛孩抬起前腳握一握。 |
| 轉圈圈 | 原地旋轉，揚起一點小灰塵。 |
| 後空翻 | 蹲低、起跳，在空中翻一圈落地。 |
| 中槍 | 主人比手槍「砰！」，毛孩搖晃倒地裝死，再跳起來。 |
| 喬登三段跳 | 連續小跳後，接一個高高的滯空飛躍。 |
| 跳火圈 | 主人舉起火圈，毛孩助跑穿過去。 |
| 麥可舞步45度傾斜 | 戴上小帽子，在聚光燈下前傾，主人在旁加油。 |

番茄鐘正在專注時，主人維持工作，毛孩可以自己表演；跳火圈改用放在架子上的火圈。如果表演進行中才開始專注，主人也會回到工作安排，讓毛孩完成演出。

**每隻寵物、每個已學會的把戲，每天第一次表演都各有一次獎勵**，畫面會標示當日是否表演過；重複看仍可以，只是不重複發當天同一把戲的首次獎勵。表演與訓練不同：不必每看一次就重新做四題測驗。

## 商店收納與佈置

### 先買，再擺

商店可購買主題房間、家具、小物、植物、牆面裝飾、地毯、壁紙、地板、窗景、寵物與消耗用品。商品會顯示所需等級與價格；長清單可搜尋名稱、篩選分類、依等級／價格／名稱排序，並翻頁瀏覽。

家具買下後通常放在**收納箱**，按「馬上擺放」或到「收納 → 物品」選擇擺放。壁紙、地板與窗景則屬於已購外觀，往後可以從收納箱免費切換。

### 佈置模式

1. 點下方「佈置」，或在收納箱按「佈置房間」。
2. 點選家具，拖曳到喜歡的位置。
3. 用工具列「翻轉」改變朝向；可切換的燈與窗簾也有對應操作。
4. 不需要時按「收起」，物品回收納箱，可再次擺出。
5. 按「完成」或 `Esc` 離開佈置模式。

家具收起不是賣掉，不會返還金幣。若家具上擺著小物，收起時會一起收進箱子，避免小物留在半空中。

小型擺飾可以放到可承載的桌面、櫃面；接近合適表面時會對位。家具、牆面物件與地毯有自己的擺放區域，不是每一件都能任意當成桌上小物使用。

### 想讓房間舒服，可以先顧這三件事

- **工作區**：書桌附近留工作椅，讓專注時有清楚的工作位置。
- **寵物區**：食碗、休息墊和活動空間不要全擠在畫面邊角；多隻寵物時考慮多個碗與休息點。
- **動線與觀看**：大型家具放得太滿，會讓毛孩不容易被看見。留一些開闊地板，看散步與互動會更有生活感。

原木書桌、小木椅、寵物碗與圓坐墊在早期即可購買。新遊戲已放好的設施能繼續沿用，不必看到攻略提到就重買一套。

## 角色造型

「造型」提供膚色、眼睛、眉毛嘴巴、瀏海與後髮、上衣、褲裙、鞋子、帽子、眼鏡耳飾，以及頸部和背部裝飾。各部位有免費基本款，其餘依玩家等級開放購買。

點尚未擁有的款式，可以**先試穿再決定**；預覽變了不代表已買到，還要按購買才會加入收藏。已擁有的款式則可直接換上，並用「轉一圈」查看正面、側面與背面。

顏色與衣服款式分開收藏。服裝染色買下後，可用在對應的不同衣服上，不必每件各買同一種顏色。「隨機」則以已擁有的款式搭配。

喜歡的造型可以存成套裝，最多 **8 套**，以後一鍵換回。刪除套裝只是移除那組搭配，不會刪掉你買過的款式。名字統一在右上角帳號設定。

## 禮物折價券與扭蛋

### 升級禮物盒

玩家升級後，房間裡會出現禮物盒，要點一下打開。可能獲得家具、金幣或折價券。

禮物盒的公開家具機率為 **25%**。如果連續 **4 盒**沒有家具，**下一盒必定開出家具**；開到家具後重新計算。獎勵視窗會提示目前情況，不需要另外手動登記。

開出的家具放進收納箱，可以收下再慢慢擺，或按「馬上擺放」。家具以外的獎勵也有用：金幣可以存向目標，折價券則留待適合的購物時機。

### 抽獎券

成功幫好友忙，累積每 **10 次**可得到 **1 張抽獎券**；在「好友」視窗查看持有數量並使用。可能得到家具、金幣或折價券。

抽獎券與升級禮物盒是兩種不同來源。**抽獎券沒有禮物盒的連續未中家具保底，也不會推進禮物盒的保底進度。**

### 折價券

折價券有 **9 折、8 折、7 折**，從取得時開始計算 **30 天有效**。購買前先在券列選一張，下一筆符合類別的成功購買就會使用；折價後價格會先顯示出來。

| 規則 | 說明 |
| --- | --- |
| 每次購物 | 一筆只能用一張，不能疊加。 |
| 每日限制 | 所有商店合計一天只能成功使用一張，06:00 後重置。 |
| 有效期限 | 取得後 30 天到期，券列可查看剩餘時間。 |
| 可使用 | 家具擺飾、壁紙、地板、窗景、角色造型、寵物工具／玩具、寵物配件。 |
| 不適用 | 主題房間、扭蛋費、寵物領養、消耗道具、旅行商人。 |

選好券後若買的是不適用的東西，該筆不會打折，也不會消耗這張券；購買前看清價格即可。一天只能用一次，適合留給原價較高、真的想買的東西；同時記得先看快到期的券。

### 扭蛋與重複款式

扭蛋機是需要先取得並擺進房間的互動家具，不是每次開商店都能直接抽。點房間裡的扭蛋機，每次消耗 **80 金幣**，獲得一件隨機小物或牆面裝飾。

抽到新款會進收納箱；抽到已在房間或收納箱裡的款式，會讓你選：

- **收進收納箱**：保留另一件，拿來成對擺設或搭配。
- **賣掉**：得到該商品原價 **30%** 的金幣，取整數。

這個賣價看的是**商品原價**，不是 80 金幣扭蛋費。若還沒決定就關掉視窗，下次會再顯示待處理的結果，先完成選擇才能繼續抽。

## 每日任務與成就

### 每日任務怎麼看

每天通常有 **5 項任務**：固定的「完成今日單字」、一項購物目標，再加上當日抽出的生活或學習任務。每張卡會列出目標、目前進度與獎勵。

「前往」只是帶你到對應功能，**不代表已完成**。完成後按「領取」；五張都領好，才能再拿「全部完成獎勵」。前一天未領的每日獎勵不會自動搬到新一天，換日前記得查看。

### 可能出現的任務與基礎獎勵

| 指定家具購物 | 購買當天指定的一件 | 依商品顯示金幣；20 經驗 |
| 專注 | 依卡片要求累積 25 或 50 分鐘 | 30／25 |
| 完成待辦 | 2 件 | 20／15 |
| 滿足需求 | 2 個 | 25／20，另有隨機道具 |
| 餵寵物 | 2 次 | 15／10 |
| 摸摸寵物 | 5 次 | 10／10 |
| 陪寵物玩 | 2 次 | 15／12 |
| 梳毛或洗澡 | 1 次 | 12／10 |
| 訓練寵物 | 完成 1 次訓練測驗 | 20／20 |
| 測驗答對 | 累積 15 題 | 25／25 |
| 佈置 | 擺放或移動 3 次 | 15／10 |

表列為任務本身的基礎獎勵，**不是每次做該動作都會直接領一遍表中的金幣**。一般任務金幣還可能受到舒適度加成。

今日單字的連續完成天數，會讓這張任務的金幣逐步加碼，最多額外 **50 金幣**。所有每日任務領完，再領 **40 金幣、30 經驗與兩份隨機用品**的全部完成獎勵。

指定購物任務要在當天**實際購買指定款式**才算；已經擁有、從箱裡擺出，不能代替購買。買完則可以按自己的佈置需求決定要不要立刻擺。

成就位於「任務 → 成就」，每種都有多個階段。達到目標後要按領取，再往下一階段前進；除了金幣、經驗與用品，部分階段還有紀念家具。

| 成就方向 | 計算內容 |

| 專注達人 | 累積專注時數。 |
| 貼心室友 | 完成的需求數。 |
| 最好的朋友 | 與一隻寵物達到的羈絆等級。 |
| 毛小孩家族 | 飼養的寵物總數。 |
| 拉拔長大 | 一隻寵物達到的成長等級。 |

成就卡會顯示目前進度與下一個目標，不用一次追完。把成就當成生活紀錄，比為了一個數字把每件事都重複點很多次，更能看見自己逐漸累積的成果。

## 好友與名片

好友、排行榜與團隊功能，需要登入雲端帳號並完成同步。自己的學習、照顧與房間玩法不必等到找到朋友才開始。

### 名字與狀態

在右上角帳號設定姓名，最多 **7 個中文字或 14 個英文字**；中英混合依欄位剩餘格數計算。這個名字會用在名片、好友與排行榜。

另可設定一行簡短狀態，例如「今天先讀完一章」。狀態欄最多 20 格，中文通常占兩格、英文字占一格。寵物名字與玩家名字是分開設定的。

### 加好友流程

1. 到「好友」查看自己的 **6 碼好友代碼**，可複製給朋友。
2. 在代碼欄輸入對方代碼，按「查詢」。
3. 確認名片後按「加好友」，送出邀請。
4. 對方到「好友邀請」按「接受」，雙方才正式成為好友。

好友上限 **30 人**。送出尚未接受的邀請，可以取消；收到邀請可以接受或拒絕；已是好友也可以刪除。刪除後就不能再以好友身分拜訪或幫忙，過去留言本中的幫忙紀錄則會保留。

### 名片能看見什麼

名片會展示名字、狀態、造型、等級、好友代碼、本週與總專注時間，以及房間與在家寵物的展示。從排行榜或團隊看到一位玩家時，也能先看名片；**看名片不等於已成為好友**，正式拜訪與互相幫忙仍要完成好友接受流程。

## 拜訪與互相幫忙

### 拜訪的玩法

在好友列表按「拜訪」，可以看看對方最近分享的小窩與寵物。如果有需要幫忙的項目，就會出現對應操作。拜訪畫面不是雙方必須同時在線的即時共同房間，好友離線時也能留下幫忙。

你能幫的項目有三種：**餵飢餓的寵物、替枯黃植物澆水、清掃積灰塵的家具**。必須真的有對應需求，不能對健康植物或沒有需求的寵物重複幫忙領獎。

### 每日次數

| 項目 | 規則 |
| --- | --- |
| 每日第一次成功幫忙 | 免費，不需要先答題。 |
| 當日後續幫忙 | 先做 4 題單字測驗，答對至少 3 題。 |
| 成功次數上限 | 所有好友合計每天最多 5 次。 |
| 答題失敗 | 不扣成功幫忙額度。 |
| 同一需求被其他人搶先處理 | 不扣成功幫忙額度，也不消耗尚未使用的當日免費機會。 |
| 換日 | 隔天 06:00 重置。 |

**免費一次是全部好友共用，不是每個好友各送一次。** 例如今天先免費幫 A 餵食，再去 B 家幫忙，就要通過單字測驗。

### 效果與回饋

成功幫忙，幫手得到 **5 金幣、5 經驗**；每累積成功 10 次，再得一張抽獎券。被幫忙的需求會先由該次成功幫手占用，其他人不能再幫同一筆。

效果會在屋主下次進入遊戲、讀取幫忙紀錄時套用；已在線的屋主，也可能等下一次檢查後才看見。成功套用時，屋主得到小額金幣，寵物餵食也能增進羈絆。這不是替屋主一次完成所有照顧，之後仍要留意毛孩狀態。

如果屋主已經自行解決同一需求，該次來訪仍會留下紀錄，但不會再重複補狀態或領第二份同筆完成獎勵。

### 留言本與愛心

好友幫忙後，對應的寵物或家具旁可能留下小愛心，點它可以查看誰做了什麼，讀完便會收起標記。

「好友 → 留言本」可以查看紀錄，點名字看名片，或按「回訪」去對方家。第一次啟用好友功能時也會收到一本可擺放的留言本，從收納箱拿出來，便能在房間裡直接開啟紀錄。

這裡的留言本是**自動記錄好友幫忙**，不是讓玩家任意輸入長篇留言的聊天室；單純逛一圈沒有幫忙，也不代表一定會產生一筆同樣的幫忙紀錄。

## 每日與每週團隊任務

### 人數、期限與目標

| 類型 | 隊伍人數 | 期限 | 每人基礎獎勵 |
| --- | --- | --- | --- |
| 每日團隊 | 1–3 人 | 當日 06:00 至隔日 06:00 | 80 金幣、30 經驗 |
| 每週團隊 | 1–5 人 | 週一 06:00 至下週一 06:00 | 400 金幣、1 張隨機折價券 |

每日與每週是**分開的隊伍**：同時參加一個每日隊與一個每週隊沒有衝突，隊友也可以不同。這裡的「團隊」可以只有自己一人，不必等滿才開始。

同一期、同類型的玩家看到相同任務，可能是下列三類之一。每一期是其中一種，**不是三種都要做完**。

| 任務類型 | 每日全隊目標 | 每週全隊目標 | 會計入什麼 |
| --- | ---: | ---: | --- |
| 全隊專注 | 90 分鐘 | 720 分鐘 | 番茄鐘完成累積的專注分鐘。 |
| 全隊答對題目 | 45 題 | 216 題 | 各種單字測驗答對的題數。 |
| 全隊照顧寵物 | 15 次 | 72 次 | 餵食、玩耍、梳毛洗澡、吃藥與訓練等照顧紀錄。 |

目標是**整隊合計**，不會因只有一人就降低，也不會因滿隊再提高。任務卡會顯示當期目標與截止時間。

### 開隊與五分鐘組隊

到「任務 → 團隊」，選每日或每週，按「開始團隊任務」。隊伍建立後會有 **5 分鐘組隊倒數**，可以先邀好友，也可以立刻開始做任務；**加入後做的事才計入隊伍**。

如果不想等，可按「立即配對」。倒數結束還沒滿隊，會自動開放其他配對中的玩家加入；不想遇到陌生人，可以按「不要自動配對」，或在配對中按「停止配對」，保留現有隊伍與進度，只讓受邀好友加入。

若自己單獨開隊、尚未累積貢獻，配對時也可能加入另一個已有空位的隊伍。已累積進度或有隊友的隊伍，則以開放空位等待其他人加入為主。

### 快速配對與好友邀請

「快速配對」會嘗試加入開放中的隊伍，隊友可以不是好友；找不到合適隊伍時，會幫你開一隊並等待其他人，不用停在空白畫面。

邀請好友時，對方仍要接受才會加入。**本版也能邀請已在其他未完成隊伍的好友**；對方接受時可確認換隊，不再限定只能邀請完全沒隊伍的人。已完成當期任務的玩家，則不能再換隊重領。

隊伍卡與進度條會顯示各人的貢獻。配對到非好友隊友，不會自動變好友；想繼續往來，可以先看名片再送好友邀請。

### 換隊與進度

在任務達成前可以離開，再開隊、配對或接受別隊邀請。**原隊中你的貢獻會一併移除，也不會搬到新隊伍**；加入新隊後重新累積。如果當期隊伍已達成，完成名單就固定，不能再透過換隊加入其他已完成名單。

你的進度不是每秒傳給所有隊友看。一般最多約每 **5 分鐘**上傳一次，接近達標時會提早上傳；有待上傳內容時，畫面也會提供「上傳我的進度」。看到隊友數字暫時沒動，先看同步情況，不必急著重做一遍。

### 達標與領獎

**只看全隊有沒有達標，不要求每位成員達到個人最低貢獻。** 完成當下在名單裡的人，即使個人貢獻是 0，也能領到相同的完整獎勵。

獎勵不是全隊分一份，也不是自動進每人的口袋；每位隊員各自到團隊分頁領取，同一期不能重複領。過期隊伍若已完成，可以在該期結束後 **7 天內**從之前的團隊獎勵區補領。

> **實用順序**：想參加團隊時，先加入，再做今日單字或開番茄鐘。加入前已做完的進度，不會回填成這隊的貢獻。

## 排行榜

到「好友 → 排行榜」可切換四種榜單，每種只顯示 **前 30 名**。

| 榜單 | 比較的是什麼 |
| --- | --- |
| 等級 | 玩家等級；同級時會參考經驗進度。 |
| 金幣 | **累積賺取金幣**，不是目前錢包餘額。 |
| 本週專注 | 當週累積的專注時間。 |
| 總專注 | 從開始遊玩累積的專注時間。 |

買家具不會讓你因為餘額減少而失去累積賺取的紀錄。每週一 06:00 只換「本週專注」的區間，總專注不會跟著歸零。

榜單並非即時更新，每位玩家的成績大約每 **3 小時**更新一次，名單也會暫存。剛完成一輪專注卻沒立刻升名次，不代表沒計入；可以查看畫面上的名單讀取時間，稍後再重新讀取。沒有出現在前 30 名，也不代表自己的紀錄被清除。

## 旅行商人

每週會有一位商人在家門外擺攤，點房間角落的告示牌就能前往；同一週的玩家會遇到同一位商人。不同商人帶來各自的風格商品，也收購不同類別的多餘擺設。

| 商人 | 風格 | 主要收購類別 |
| --- | --- | --- |
| 青苔婆婆 | 植物、盆景與綠意收藏 | 盆栽、花瓶、小擺飾 |
| 老鐘先生 | 古董與復古物件 | 時鐘、畫、鏡子 |
| 毛球小姐 | 毛孩家具與可愛用品 | 玩偶、地毯、玩具 |
| 夜星 | 星象、月光與發光收藏 | 霓虹燈、燈、燈串 |
| 可可 | 甜點與店鋪風格擺飾 | 杯壺、書桌用品、其他合適小物 |
| 阿線 | 手作、織品與溫暖家具 | 地毯、椅子、櫃子 |

### 「他在賣」

每位商人有自己的商品，每件當週最多購買 **2 件**，仍需符合等級並支付金幣；**不收折價券**。買下後放進收納箱，並不會替你直接改整個房間。

這個件數是你當週可買的數量，不是所有玩家共用、搶完就沒有的全服庫存。喜歡的可以買一件收藏，或買兩件做對稱佈置。

### 「他想收購」

商人只收**收納箱裡**且符合本週類別的物品，不會直接賣掉你正擺在房間裡的家具。想出售正在使用的東西，要先自行收起，再到收購清單確認。

每一收購類別當週最多 **5 件**，是同類合計，不是每個款式各五件；價格約為商品原價 **40%–60%**，當週實際比例與每件金額會顯示在畫面。紀念性或特殊獎勵物件不一定可出售，以清單列出的內容為準。

旅行商人收購與扭蛋重複款式出售是兩個入口，價格規則不同。適合整理暫時不想擺的收藏，不需要為了賣東西把喜歡的房間拆光。

## 音樂與歌詞

音樂不只配合番茄鐘。你可以自由聽歌、調整清單，讓房間陪自己讀書、工作或休息。

### 三種來源

| 來源 | 使用方式 | 注意事項 |
| --- | --- | --- |
| 內建音樂 | 進「內建音樂」，依專輯／分類選曲。 | 第一次播放可能需要下載，是否可播放依提供的歌曲與連線狀況。 |
| 本機音樂 | 「我的清單 → 加入本機音樂」，或直接把音檔拖入頁面。 | 音檔保存在目前裝置，換裝置後要另外加入。 |
| YouTube | 在我的清單貼上影片或播放清單網址。 | 需要連線，能否嵌入播放也取決於影片本身。 |

介面支援常見的 MP3、FLAC、M4A、OGG、WAV 等格式，實際解碼能力依瀏覽器而定。若顯示「需重新加入」，重新選擇原本的本機音檔即可；不必重開遊戲進度。

### 播放操作

可控制播放／暫停、上一首／下一首、音量、進度、隨機播放，以及不重複／全部重複／單曲重複。「專注自動播放」開啟後，開始專注會在有曲目可用時啟動音樂。

我的清單可以上移曲目或移除；內建曲目則依專輯瀏覽與播放。播放器可調整視窗大小，依閱讀習慣留出較多歌曲清單空間。本機曲目清單最多加入 300 首。

**關閉功能視窗與暫停音樂是不同動作。** 如果只是想讓畫面清爽，可以關播放器視窗；想安靜則按暫停，迷你模式也有音樂控制。

### 歌詞

有提供對應歌詞的歌曲，能在房間上方顯示同步歌詞；可用播放器的「歌詞：開／關」切換。

自己的歌若有同名 `.lrc` 歌詞檔，可以和音樂檔一起拖進頁面。例如 `song.mp3` 配 `song.lrc`。只有歌詞、沒有一起加入對應音檔時，不會建立可播放歌曲。

### 音樂快取

播過的內建歌曲會盡可能存在這台裝置，下次不必重抓。可在播放器的裝置儲存區設定 **512 MB、1 GB、2 GB 或 5 GB**，預設 2 GB；超過容量時會優先移除較久沒聽的快取。

這是音樂檔案的裝置空間，不是金幣，也不是另一個遊戲存檔。可以按清除釋放音樂快取；下次播放需要重新下載，不會因此清掉房間、單字與寵物。

## 待辦便條與環境設定

### 待辦清單

輸入一件事後按 Enter 或新增，點方框或文字就能完成。完成一項可得基礎 **3 金幣、5 經驗**，每天最多 **15 次**獎勵；同一項反覆取消再打勾，不會一直重領。預先提供的範例待辦不發獎。

番茄鐘可以選擇一件未完成待辦作為這一輪目標。計時結束與待辦完成是兩件事，真正做完後再自己勾選。清單最多保存 100 項，每項最多 140 字元。

### 便條

可新增最多 **20 張**便條，每張最多 **2,000 字元**，有五種紙張顏色。適合記今天要背的字、讀書進度，或留一段給自己的提醒。

寬畫面可把便條「釘在桌面」，拖動便條標題調整位置。這裡的桌面指**遊戲頁面內的桌面區域**，不是把便條放到作業系統其他程式上方；窄畫面以便條視窗閱讀為主。

### 環境與迷你模式

窗外可以選「跟著現在」、白天、黃昏或夜晚，也可以切換下雨。這些是房間氣氛設定，不會把每日任務的換日時間一起改掉；切成夜景不等於進入隔天。

迷你模式保留房間與基本倒數、開始／暫停、重設、音樂控制。想少看一些面板時，可以切換；要購物、查看任務或完整照顧，再回完整模式。

## 家具裡的小互動

不少擺設有生活小反應，不只用來提高房間舒適度。依物件功能，可能出現葉片、泡泡、音符、愛心、時間或日期資訊。

| 物件類型 | 可以嘗試的互動 |
| --- | --- |
| 一般植物 | 點一下澆水或看葉片反應；枯黃需求另用營養液處理。 |
| 魚缸 | 餵魚，看水中與餵食反應。 |
| 書架或單字相關家具 | 看看會不會出現單字與發音。 |
| 咖啡機 | 取得當日可沖泡的咖啡。 |
| 小冰箱 | 看看當日可以拿到什麼食物。 |
| 直立鋼琴 | 看到演奏文字與音符。 |
| 街機台 | 玩一次得分小互動、試著刷新紀錄。 |
| 時鐘與布穀鳥鐘 | 查看現在時間。 |
| 燈與發光擺設 | 開關照明，欣賞不同時段的效果。 |
| 音響與相關設備 | 配合音樂呈現播放氣氛。 |

部分互動有當日次數限制，重複點擊主要是欣賞反應，不會無限取得資源。這些家具也各有解鎖等級與價格，看到想要的時再把它列進收藏目標即可。

## 帳號與存檔

### 登入與同步

右上角帳號可使用 Google 或 Email 登入。Email 可註冊新帳號；忘記密碼時，透過該頁寄出重設信。

日常操作會自動保存進度，登入且連線正常時再同步到雲端。帳號頁能查看狀態與上次同步時間，也可按「立即同步」。換手機、電腦或瀏覽器時，登入同一帳號接續。

若頁面顯示離線，進度會先保留在目前裝置；恢復連線後再同步。好友、組隊、排行等需要連線取得的功能，則等連線恢復後使用。

### 裝置與雲端出現不同進度時

第一次把裝置進度帶上雲端，或兩邊已有不同存檔時，可能會出現選擇畫面。請先看等級、金幣與時間摘要，再選使用雲端、匯入目前進度、合併或取代等可用選項。

遊戲會在移轉、合併或取代前建立備份，可從帳號頁的「存檔來源與備份」查看及還原。還原是用那份進度取代目前狀態，先確認日期與內容，再按確認。

單字學習、房間、寵物與金幣屬於遊戲進度；本機音樂檔與內建音樂快取仍屬於各台裝置。登入另一台電腦，不代表原電腦選過的音檔也一併搬過去。

### 關閉前的小習慣

準備換裝置或結束遊玩時，先完成正在領取的獎勵，確認帳號頁顯示已同步，再關閉頁面。若正在處理斷線、進度選擇或同步失敗，依畫面提示完成後再換裝置。

設定中的「重新開始」會清除目前遊戲進度，需要再次確認。它不是重排房間的工具；只想換風格，使用收納或主題套用就好。

## 日常遊玩安排

下面是幾種可自由選擇的玩法，不是系統額外要求的任務。

### 只有一點空檔

先看需要立即照顧的寵物，補碗或換一份用品；再做今日單字。完成後記得去任務領獎。有尚未完成的學習內容，留待下一次繼續，不必順便把商店每頁都逛完。

### 有一段讀書或工作時間

先加入想參與的每日／每週團隊，寫好待辦，再開一輪番茄鐘與音樂。專注結束後休息，順手處理需求、玩一次玩具，確認任務是否達成。這樣同一段真實專注，可以同時累積自己的成長與隊伍目標。

### 想慢慢收藏房間

先選一個近期目標，例如一個主題或一件家具。消耗用品盡量靠學習換取，金幣集中到目標；有折價券時先比較可省下的金額，再決定用在哪一筆。週更後看看旅行商人，順便整理收納箱中的重複收藏。

### 想把重心放在毛孩

不要只追求領養數，先備妥玩具、梳子、食碗與休息位置。每天看一次狀態，安排照顧、幾次訓練，再讓牠睡覺；旅館可以讓你輪流陪伴不同毛孩，不需要把十隻一起塞進房間。

### 每日與每週速查

| 時機 | 可以檢查的事 |
| --- | --- |
| 每次開啟 | 雲端狀態、寵物狀態、碗裡食物、新需求與好友幫忙紀錄。 |
| 開始學習／專注前 | 是否已加入想參與的團隊；這一輪待辦是什麼。 |
| 每日學習後 | 今日單字任務、其他可領任務、全部完成獎勵。 |
| 想做點社交時 | 好友邀請、可幫忙需求、留言本回訪、抽獎券進度。 |
| 每週更新後 | 新旅行商人、當週團隊目標、排行榜區間。 |
| 離開前 | 碗的補充、待領獎勵、雲端同步是否完成。 |

## 常見問題

### 我已經把今天的單字做完，為什麼每日任務還沒拿到金幣？

測驗結算與任務獎勵分開。先確認 20 字複習與 10 題測驗已完成，再到「任務 → 每日任務」按該卡片的「領取」。

### 為什麼自由練習還有經驗，卻少了答題金幣？

自由練習的一般答題金幣每天有 40 金幣額度。用完仍能練單字、累積學習進度；其他模式與任務則依各自規則給獎。

### 取消某級新字，怎麼還是看到那一級？

程度選擇主要控制新字。之前學過的字到複習時間，仍可能出現，這不是設定失效。

### 餵過一次，寵物怎麼還在喊餓？

食物份量不同，原本很餓時，一份小魚乾不一定足夠。看看飽足條，再決定補食物；食物只放進碗裡時，也要等牠實際去吃。

### 房間另一個碗有食物，牠怎麼不吃？

先看牠有沒有專用碗。有指定碗的毛孩優先使用自己的碗，檢查該碗是否空了；需要時補食物或改成共用。

### 梳過毛，怎麼不能馬上再梳？

同一隻寵物梳毛有 20 分鐘間隔。真的需要立刻提高大量清潔，可以考慮洗澡。

### 為什麼訓練完一次還沒學會？

4 題答對至少 3 題，是一次成功訓練。每個把戲需要數次成功累積，看進度條滿了才算學會；另外還要符合寵物成長等級。

### 表演時主人為什麼沒有走過來？

番茄鐘專注中，主人優先維持工作，毛孩會自己表演。想看主人一起握手、配合裝死或舉火圈，可以等休息時再表演。若已有另一場表演在進行，先等它結束。

### 家具買了卻沒在房間裡？

通常在「收納 → 物品」。購買只是取得物品，還要按「擺放」；壁紙、地板與窗景則在收納的對應分頁切換。

### 我有需要的家具，為什麼毛孩還想要？

家具願望要求房間裡有指定款式。收在箱子裡不算，名稱相近的另一款也不一定相同，依需求卡確認。

### 我選了折價券，這次怎麼沒折扣？

先看是否屬於主題、領養、消耗用品、扭蛋或旅行商人等不適用項目，再看今天是否已用過、券是否到期。符合條件時，購買前就會顯示折後價格。

### 團隊裡有 0 貢獻的人，能不能領？

可以。只要在達標時的完成名單上，全員都有相同的完整獎勵，沒有個人最低貢獻要求。

### 我換隊之後，原本做的內容會帶過去嗎？

不會。原隊貢獻會隨離開而移除，新隊從加入後重新計算；已完成當期任務的隊伍則不能再換。

### 我才進隊，怎麼之前做好的單字不算？

團隊只計入加入後發生的行為。想兼顧今日學習與團隊目標，先入隊再做題。

### 我幫好友餵食，對方怎麼還沒看到？

幫忙先留下紀錄，等屋主下次進入或讀取幫忙後套用，不是立刻遠端改動對方畫面。同一需求被別人先幫掉時，你這次不扣成功次數。

### 我花掉金幣，金幣排行榜會掉下去嗎？

榜單看累積賺取，不看餘額；購物不會扣掉過去已賺的紀錄。排行榜也不是即時更新，請看畫面上的更新時間。

### 旅行商人怎麼不收我正在用的家具？

先看是不是當週收購類別，再看物品是否在收納箱，以及該類本週五件額度是否用完。商人不會直接從房間裡替你拔走家具。

### 換手機後，我的房間回來了，音樂為什麼沒有？

遊戲進度與本機音檔分開。本機歌曲要在新裝置重新加入；內建音樂則依需要在新裝置重新下載。

### 迷你模式可以讓遊戲置頂在其他程式上面嗎？

本版的迷你模式是網頁內的精簡介面，沒有跨程式視窗置頂或縮到作業系統匣的功能。日常使用仍由瀏覽器視窗控制。
