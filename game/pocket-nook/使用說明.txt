更新日期：2026-10-27

更新方式
請完整覆蓋原站台檔案，包含 index.html、js/、css/、sw.js 與 version.json。
不要只更新 version.json。若頁面仍停在舊入口，可將網址改成 index.html?build=0.92.2 開啟一次。
請保留原 music/ 內的 MP3、字幕與封面。本次使用的來源壓縮檔沒有附 MP3。
使用 HTTP / HTTPS 伺服器開啟，從 index.html 進入。
Firebase 設定維持原檔 js/firebase-config.js；更新不會清除本機存檔，也沒有變更存檔格式。

這次修正
1. 版本集中由 index.html 宣告為 0.92.2；遊戲存檔版本、設定視窗與更新判斷使用相同版本。
   所有程式與樣式網址加上版本參數，避免新舊檔混用。更新時處理本遊戲快取，使用新網址重新載入。
   Service Worker 的程式碼請求在線上會略過 HTTP 快取；離線使用精確對應的快取檔。
2. 同折數折價券只顯示一個項目，數量加總、天數取最早到期的一張。
   例：三張九折券分別剩 1、10、15 天，顯示「9折券 x3 剩1天」。數值或字串形式的同折數會合併。
   使用時優先消耗最早到期的一張，仍維持每日限用一張的原規則。
3. 開場使用根目錄 apple-touch-icon.png，放大顯示。圖示顯示後至少停留 3 秒；快速載完也不提早進房。
   原有完整預載 HD-2D、等待雲端與 30 秒逾時機制保留。
4. 手機拿取道具後，房間顯示浮動道具圖，並在房間下方標示目前拿取的物品與操作提示。
   觸碰／拖曳時，道具圖位於手指上方，操作位置以圓圈標示；逗貓棒的羽毛位置在手指上方約 48px。
   圖示使用獨立介面圖層，像素與 HD-2D 都可見；逗貓棒、小魚乾、罐頭均已以觸控事件測試。
