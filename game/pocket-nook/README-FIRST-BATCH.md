# Pocket Nook 0.92 — 第一批 HD-2D 家具

將壓縮檔中的 `js`、`assets` 資料夾合併覆蓋到目前遊戲根目錄。重新整理網頁即可，毋須修改 index.html，也沒有調升遊戲版本。

本批完成 49 個家具基礎造型，涵蓋 214 個商品項目與配色：收納、座椅、沙發、層架及六組主題書桌／椅子。另追加 11 款椅背 HD-2D 素材，以及原像素版椅背，支援現有 39 款可搭配書桌的椅子與配色。

選用保留書桌、補齊椅背的方案。椅子靠近書桌，或人物坐在該椅子用功時顯示背面；獨立擺放時保留正面。人物坐姿的椅子遮擋層同步使用背面。原始商品 ID、存檔位置、家具尺寸與承載座標維持既有規則。

`preview.html` 可直接開啟查看全部素材與椅背對照。`HD2D-BATCHES.json` 保存完整五批清單，第一批已完成；後續從第二批接續。

安裝內容：
- `js/hd2d.js`：獨立 HD 圖包載入、配色快取及兩種模式共用的椅子方向判斷。
- `assets/hd2d/objects.json`、`objects/`：60 張 HD-2D 家具圖（49 正面＋11 椅背）。
- `assets/sprites/chair-backs.json`、`chair-backs/`：11 張像素椅背與執行時使用的像素資料。

原像素家具正面仍保留。HD 場景維持 2 倍畫布，沿用既有光照、短距離輪廓影子與天氣修正。單張 HD 圖片載入失敗時，會使用原像素素材或其細節化版本。
