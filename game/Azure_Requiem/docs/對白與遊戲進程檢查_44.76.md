# 對白與遊戲進程檢查（第 44.76 版）

## 檢查方法
- 第二關：用 `test/d02audit-test.ts` 讓玩家由 AI 代飛，從開場一路打到勝利，共 2449 秒。每句台詞開口的那一刻，都記下當時的遊戲狀態：階段、迷彩、冷卻、距離、干擾、震盪束、HP、引擎、敵機、部件、RAVEN、高度。逐句對照。
- 第一關：用新寫的 `test/d01audit-test.ts`（同樣由 AI 代飛）打到勝利，共 456 秒。每句記下：波次、敵機組成、Cerberus 存活數、動畫、玩家 HP、最近敵機距離、僚機。逐句對照。
- 通用台詞（KIL／THR／ACK／ACT／ALL／LCK／FLT 等）：直接讀 Radio.ts 的觸發條件，檢查台詞內容有沒有被條件保證。
- 測試沒有涵蓋的部分：
  - 玩家實際操作才會出現的分支：被擊落、僚機陣亡、各種失敗結局。
  - 第一關勝利之後的結尾對白（測試在結果出來時就停了）。
  - 第二關補給選單的真實等待時間（測試在 3 秒內自動完成補給）。

下面每一條都列出：台詞編號、台詞、實際狀態、建議的修法。標【提案】的是我的建議，要等導演決定。

### G. 被警告語音打斷後從頭重說（同一類，一次修）
- 實例：
  - 10107 說了兩次。
  - 第四階段：10033「主引擎擊毀一具！」、10112B 兩句、10113、10031、10032、10120、10094，每句都完整重講一次。
- 原因：Radio.ts 第 556 行的規則是劇情台詞被 WARNING SYSTEM 打斷後放回佇列，之後從頭說。第四階段震盪束約 25 秒一發，幾乎每句都撞上。
- 【提案】三選一：
  - (a) 已經說了 60% 以上的就不重說。
  - (b) 多段台詞只補沒說的段落。
  - (c) 短句（4 秒內）不重說。
  - 我建議 (a) 加 (b)。
