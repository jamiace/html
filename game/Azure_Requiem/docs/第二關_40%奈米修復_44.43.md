# 第二關：ANZU HP 40% 奈米修復橋段（44.43，使用者指定）

取代 44.00 版「40% 立刻藍光 10 秒、修好就開放傷害」。

## 流程（動畫）
1. **HP 40%**：進入動畫（sim.cine 'repair'）。鎖血，本體與部件都不受傷；沒有方框、選不到、鎖不到。ANZU 不攻擊、不反擊任何目標（震盪束、CIWS 雷射、AAM、AA GUN），也不干擾。正在充能的震盪束（不論目標）取消，倒數面板與倒數語音一起清掉。場上所有 UAV 移除（不爆炸、不算擊墜）；玩家與僚機暫停；排隊中的戰鬥對話清掉。
2. LUGAL、火控官下令啟動奈米修復（10135 → 10136 → 10137）。
3. 火控官講完 **3 秒**後，奈米修復 **10 秒**：震盪束集氣的藍光（流動的光斑）覆蓋全身，全身各處冒出集氣的光點與藍白煙（跟著機體移動）。
4. 修復結束：所有部件恢復（冒煙停止）。動畫期間被擊毀部件的煙照常拖出長長的煙帶。
5. 僚機的反應：10138 → 10108 → 10109 → 10139 → 空管 10140【擊墜 ANZU】→ 講完 **2 秒**離開動畫。
6. 離開動畫：玩家搬到 ANZU 正後方 **35,000 ft**（同高度、機頭與 ANZU 同方向），僚機排好隊形；飛向我方的飛彈清掉。開放方框、選取、攻擊、傷害，ANZU 開始反擊；任務目標【擊墜 ANZU】。
7. 再過 **3 秒**放出這個階段的第一批無人機（20 架）；25 秒後 LUGAL 10111。
- 鏡頭：整段繞著 ANZU 平順移動（開始在左前上方約 2.3 km，30 秒內拉近到 1.75 km、慢慢繞到側後方），只由經過的秒數決定。沒有徽章與名稱。
- 修復期間一直現形（使用者指定）：當作五座 CIWS 都在冷卻，迷彩自然解除；開放之後 10 秒內五座全部恢復冷卻 → 照原本規則重新進入迷彩，要再被觸發冷卻才會現形。修復期間不擲震盪束。
- LUGAL 10107「本艦不需要再躲了」維持在 20% 才講（使用者確認）。
