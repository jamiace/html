# R37 血月哥德美術版

基準：R36 Multi Canvas 固定 60 FPS 版。遊戲邏輯、數值、碰撞與操作完全沒有更動，只改「畫面」。

## 圖片
- 全部 54 張原有圖片重繪為血月哥德風（檔名、尺寸不變）。
- 新增 18 張特效貼圖（assets/fx_*.png）：燃燒區、腐蝕池、隕石符文法陣、重力奇點漩渦、衝擊波、雷射光束與光暈、斬輪、滑鼠準星、護盾氣泡、道具光環、Boss 長矛、毒液彈、Boss 火球、Boss 秘法星、敵彈碎晶、冰封外殼、電光火花。

## 畫面改動（game.js）
- 燃燒區、腐蝕池、隕石警示圈、重力井、衝擊波、雷射、斬輪、準星、護盾、道具光環、凍結效果改用貼圖。
- 雷弧改為三層加亮描邊加節點火花；玩家子彈與敵彈尾跡改為漸細彗星尾；粒子改為柔光圓點。
- 敵彈本體改用貼圖；碎晶彈會依原本設定的顏色自動染色。
- Golem／Boss 血條加金框；傷害數字改襯線字加深色描邊。
- 背景暗角加入右上角血月微光。
- 所有新貼圖都有 fallback：圖片缺失時自動回到原本的程式繪製。

## 效能
- 火焰粒子、一般粒子、傷害數字、地圖道具、雷弧不再使用每幀 shadowBlur，改用預先算好的貼圖或加亮混合，效能負擔應與 R36 相同或更低。
- 染色貼圖會快取，每種顏色只建立一次。

## 介面（style.css / index.html）
- 在 style.css 末尾加上一層哥德風覆寫：金框面板、酒紅按鈕、襯線標題、血條與經驗條。
- index.html 載入 Google Fonts 的 Cinzel 字體；離線時會自動改用系統襯線字。

## 設定（game-config.json）
- assets 新增 18 個特效貼圖路徑。
- visuals 調整：燃燒／腐蝕區透明度、傷害字體與描邊、血條顏色與金框、火焰粒子混合模式、暗角與血月光、地板透明度、環繞刃軌跡顏色。

替換整個資料夾後，請完整重新整理頁面（Ctrl+F5）。
